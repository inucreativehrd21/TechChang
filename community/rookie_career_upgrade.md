# 야구선수 키우기 커리어 개편 · 2026-10-21

후속 [야구 문구 전수 점검](rookie_text_audit.md)에서 리그·보직·상황별 중계 용어를 교정했어요. 현재 카드 캐시 버전은 8이며, 아래 버전 7 설명은 커리어 개편 당시 기록이에요.

정식·라이트의 공용 경기 모형과 카드, 개인 커리어 세계를 개편했어요. 기존 사용자 저장 데이터를 지우지 않고 `career`/`flags` JSON을 사용해요. 운영 배포·DB 마이그레이션 적용은 하지 않았어요.

## 적용한 내용

| 요청 | 최종 동작 |
|---|---|
| 유니폼 이름·등번호 | 이름은 어깨 아래의 얕은 곡선에, 번호는 등 중앙에 좁고 긴 비율로 배치했어요. 한 자리/두 자리 폭을 나누고 테두리를 줄였어요. 카드 정보·스탯 위치는 유지해요. 캐시 버전은 7이에요. |
| 해외 구단 카드 | KBO 10종 원단을 해외 48팀에 공유해요. 양키스 등 핀스트라이프는 두산, 주황은 한화 등 가까운 배색으로 묶어요. 대응 원단이 없는 녹색·노랑은 KT 중립 원단을 써요. 원래 구단명·카드 색·선수 이름과 번호는 유지해요. |
| 고졸 MLB 오퍼 | 기존 잠재력·스카우트 경로에 더해 실제 졸업 성적이 뛰어나도 MLB 3팀 제안을 받아요. KBO 드래프트·대학 선택도 유지해요. 고졸 MLB 입단은 싱글A부터 시작해요. |
| 미국 초기 성장 난도 | 고졸 미국 직행 이력의 24세 미만 A/AA 선수에게 성장·훈련·경험 보정을 적용해요. 대졸·성인 포스팅은 제외해요. 자기 관리와 나이에 따라 완화되고, 잠재력 90은 적응 손실이 작아요. 화면과 능력 변화 장부에서 확인할 수 있어요. |
| 안타 빈도 | 모든 공용 타석에서 안타·장타·홈런 확률에 0.96을 곱하고 남은 확률은 범타로 옮겨요. 볼넷·사구 확률은 그대로예요. |
| 극단 성적 | 능력 대결의 차이 12점까지는 기존 효과를 유지하고, 이후 완만하게 18점 효과에 접근해요. 능력치 자체는 깎지 않아요. 낮은 리그에서 극단적인 성적이 여러 시즌 반복되는 현상을 완화했어요. |
| 지속 라이벌 | 시작 경쟁자 3명과 새 구단의 같은 포지션 경쟁자를 최대 9명까지 기억해요. 이름·관계·성장·승격·이적·부상·대화 이력이 이어져요. 화면에는 최근 5명을 보여 줘요. |
| 구단 일정과 순위 | 같은 커리어 안의 구단들이 하나의 대진표와 점수를 공유해요. 개인 출전 경기의 점수도 해당 대진에 반영해요. 승패·무승부·득실·월별 순위는 그 결과에서 계산해요. |

졸업 성적 경로는 싱글A 수준에 근접한 현재 OVR도 요구해요. 타자는 충분한 타석과 타율 .340·OPS 1.050 이상, 투수는 충분한 이닝과 ERA 2.00 이하·삼진 표본을 함께 봐요. 소수 타석이나 잠재력 하나만으로 성적 경로가 열리지는 않아요. 이 기준과 미국 육성 보정은 실제 구단의 정량 기준이 아닌 게임 설계예요.

## FM과 비교해 바로 보완한 몰입 요소

초기 비교는 [몰입 구조 검토](rookie_immersion_review.md)에 있어요. 이번에는 같은 사람과 구단이 이어지고, 선택을 기억하며, 결과를 되짚을 수 있는 부분을 먼저 구현했어요.

- 라이벌과 함께 훈련하면 자기 관리·관계·신뢰가 오르고, 정면 경쟁은 승부에 따라 자신감이 달라져요. 공개 비난은 인기를 얻어도 관계와 신뢰를 크게 잃어요. 면담 결과도 같은 경쟁자의 이력에 남아요.
- 감독을 육성·성적·팀워크 중심으로 나눴어요. 성적 중심 감독은 역할 요구를 더 엄격하게 보고, 육성 중심 감독은 추가 훈련을, 팀워크 중심 감독은 동료 관계를 더 크게 평가해요.
- 기존 자신감·자기 관리·신뢰·인기·인터뷰 약속을 실제 경기력·훈련·출전·수입·협상에 연결한 규칙은 유지해요. 선택 뒤 숫자와 사건이 다음 시즌으로 이어져요.
- 순위는 더 이상 내 WAR를 넣어 뽑은 추정 순위가 아니에요. 내 경기 결과를 상대 구단의 같은 경기에도 반영하므로 한 팀의 승리는 다른 팀의 패배가 돼요. KBO·NPB는 일부 무승부도 생겨요.
- 라이트 가을야구는 실제 상위 5개 구단의 대진을 따라 WC→준PO→PO를 계산해요. 정규시즌 1위는 한국시리즈로 직행하고, 내 구단이 진출하면 실제 다른 진출 구단과 마지막 승부를 해요.

KBO의 WC 4위 우위와 준PO·PO 3선승 구조를 반영했어요. 한국시리즈 자체는 기존 결정적 순간으로 압축해요. 우천 순연·포스트시즌 연장 무승부·전 경기 7전제 재현까지 구현한 것은 아니에요. 근거는 [KBO의 2026 포스트시즌 안내](https://koreabaseball.com/MediaNews/Notice/View.aspx?bdSe=12183)예요.

## 야구 기록과 시즌 전환 수정

- 희생플라이는 타석에 포함하고 타수에서는 빼도록 추가했어요. 타격 쪽 득점 장면은 원래 주자·아웃 상태를 근사하므로 희생플라이 발생도 확률 모형이에요. 집계 기준은 [MLB 희생플라이 설명](https://www.mlb.com/glossary/standard-stats/sacrifice-fly)을 확인했어요.
- 투구 모형의 2루타에서 1루 주자의 득점과 3루 잔류를 각각 추첨하던 부분을 한 번의 판단으로 묶었어요. 주자가 중복되거나 사라지는 경우를 막아요.
- MLB 계약 만료 후 일본 구단에 입단할 때 이전 미국 구단의 콜업 예약이 남아 리그와 구단이 어긋나던 오류를 실제 시뮬레이션에서 찾았어요. 계약 만료·새 계약·이적 때 예약을 정리하고, 예전 저장본의 다른 리그 승강 예약도 무시해요. 같은 실패 시드를 재현한 뒤 은퇴까지 완료되는 것을 확인했어요.

## 실제 커리어 100회와 극단 조건 12회

최종 원본은 [rookie-balance-20261021.json](reports/rookie-balance-20261021.json), 극단 보정 전 비교 자료는 [rookie-balance-20261020.json](reports/rookie-balance-20261020.json)이에요.

가짜 성적을 생성한 것이 아니라 `create → run_season → decide → next_season`의 실제 라이트 진행 함수를 고교부터 은퇴까지 실행했어요. 기본 잠재력 추첨을 사용하는 타자 50명·투수 50명, 시드 `20261020…20261119`, 안정·미국 선호·강한 협상 정책을 섞었어요. 추가로 잠재력 60/84/90 × 국내 잔류/미국 선호 × 타자/투수 12명을 완주했어요. 훈련 강도는 보통이며 모든 훈련·소비·선택 조합을 탐색한 실험은 아니에요.

| 검사 | 최종 결과 |
|---|---:|
| 일반 커리어 완료 | 100/100 |
| 일반 커리어에서 치른 시즌 | 2,105 |
| 추가 극단 커리어 완료 | 12/12, 260시즌 |
| 진행 예외 | 0 |
| 기록·리그 불변식 오류 | 0 |
| 일반 커리어 평균 길이 | 21.05시즌 |
| 일반 표본 MLB 도달 | 35명 |
| 일반 표본 고졸 미국 직행 | 3명 |
| 종료 시 상태 JSON 최대 크기 | 44,563바이트 |

승=패 합계, 득점=실점 합계, 각 구단의 정해진 경기 수와 승+패+무 보존, 선수의 HR≤H≤AB≤PA, 투수 승패·이닝 범위, 구단과 소속 국가 일치, 유효 순위·유한 수치·정상 은퇴를 검사했어요. 임시 테스트 DB만 사용해 로컬 플레이어 기록을 추가하지 않았어요.

유효 표본을 가진 선수 시즌의 단순 평균은 다음과 같아요. 성장·훈련을 한 내 선수들만 집계하므로 **전체 리그 평균이나 현실 야구의 예측값은 아니에요.**

| 리그 | 타자 시즌 수 | 평균 타율 / OPS | 투수 시즌 수 | 평균 ERA |
|---|---:|---|---:|---:|
| KBO 1군 | 538 | .281 / .804 | 515 | 3.268 |
| MLB | 143 | .295 / .845 | 136 | 3.197 |

공통 안타 하향만 분리하면 동급 대결의 타석당 안타 확률은 .24451→.23473으로 상대 4% 감소해요. 능력 격차가 큰 구간은 별도의 대결 차이 완화도 함께 적용되므로 이전 엔진 전체 대비 변화량이 정확히 4%인 것은 아니에요.

미국 적응 효과는 난수와 훈련·출전 조건을 동일하게 둔 별도 4년 쌍 비교예요. 아래 표는 완주 표본의 서로 다른 선수를 비교한 값과 구분해요.

| 잠재력 | 국내 OVR | 고졸 미국 A 잔류 OVR | 차이 |
|---|---:|---:|---:|
| 76 | 68.0 | 60.8 | -7.2 |
| 84 | 70.6 | 63.6 | -7.0 |
| 90 | 72.2 | 70.6 | -1.6 |

극단 보정 전후 완주 실험에서 잠재력 84 국내 타자의 최고 시즌 WAR는 15.1→13.1, 잠재력 90 국내 타자는 14.6→9.9였어요. 잠재력 84 국내 투수의 KBO 시즌 평균 ERA는 1.360→1.626이었어요. 엔진의 난수 소비와 이후 진로가 달라지므로 한 시즌씩 짝지은 인과 비교는 아니에요.

최상위 재능의 국내 장기 잔류는 여전히 강해요. 추가 표본에서 최저 단일 시즌 ERA 약 0.70, 최고 시즌 WAR 13.1이 남았어요. 보통 표본에서 최고 237안타·46홈런·26승이 나왔어요(각 수치의 선수와 시즌은 달라요). 진행·기록 붕괴는 발견하지 못했지만, 희귀한 초고잠재력의 극단값까지 현실 범위로 보장하거나 모든 전략이 동등하다고 결론 내리지는 않아요. 이를 억지 성적 하한으로 자르지는 않았어요.

## 검증과 로컬 확인

- 야구 관련 8개 모듈의 전체 **260개 테스트가 통과**했고 `manage.py check`도 문제없었어요. 마지막 계약 전환 수정까지 포함한 결과예요.
- 모바일 UA와 `force_version=mobile` 쿠키로 라이트 미리보기 20종, PC 정식 미리보기 17종을 열어 HTTP 200·가로 넘침 없음·JavaScript 오류 없음을 확인했어요.
- PC·390px 모바일에서 라이벌과 순위표를 펼쳐 스크린샷을 직접 봤어요. KT 이재원 20번과 해외 공유 유니폼 카드의 이름·번호 비율도 직접 확인했어요.
- 순위표는 모바일에서 내부 가로 스크롤을 지원하고 키보드 포커스·표 머리글·캡션을 제공해요.
- 정식은 일일 경기·계약·훈련 회귀 테스트와 공용 확률 모형으로 검증했어요. 100회 완주 수치는 라이트 커리어에 해당해요.

재현 명령(Python 런처가 정상인 환경):

```powershell
$env:DJANGO_SETTINGS_MODULE='config.settings.local'
py -3.10 manage.py rookie_balance --output community/reports/rookie-balance-20261021.json
py -3.10 manage.py test community.test_rookie community.test_rookie_career community.test_rookie_league community.test_rookie_lite community.test_rookie_story community.test_rookie_contracts community.test_rookie_universe community.test_rookie_preview --noinput
py -3.10 manage.py check
```

이번 재개 환경에서는 런처가 Python 설치를 찾지 못하고, 기본 site 초기화도 멈췄어요. 기존 Python 3.10.11 실행 파일을 `-S`로 열어 site-packages를 표준 라이브러리 뒤에 추가하고 동일한 `manage.py`를 실행했어요. 시스템 설치·프로젝트 설정은 바꾸지 않았어요. 샌드박스에서 Daphne의 로컬 socketpair 초기화가 멈추는 문제는 승인된 로컬 실행으로 확인했어요.

미리보기는 DEBUG 전용 `/rookie/preview/`예요. `scene=world`, `scene=rival`, `scene=cards&club=nyy`, `scene=negotiation` 등으로 열어요. 개인화·선택 체험은 실제 선수 DB를 바꾸지 않아요. 이미지 생성은 제작 때만 사용한 정적 에셋이며 플레이 중 유료 모델 호출을 추가하지 않았어요.

## 남아 있는 구현 한계

| 영역 | 현재 경계 |
|---|---|
| 리그 세계 | 한 선수의 커리어 안에서 일관된 리그예요. 여러 실제 회원이 같은 구단 승패를 공유하는 전역 리그는 아니에요. 기존 회원 리더보드는 별도로 유지해요. |
| 일정·로스터 | 경기 수를 맞춘 순환 대진이에요. 현실 MLB 지구 편성, NPB 양대 리그, 우천 순연·홈구장 사정까지 복제하지 않아요. 다른 구단 점수는 구단 전력 모형이며 전 선수 로스터를 9이닝씩 시뮬레이션하지 않아요. |
| 개인 승부 장면 | 일반 이벤트 선택은 자신감·신뢰를 통해 이후 경기력에 연결돼요. 이미 계산한 공식 기록의 한 타석을 교체하는 경기 중단 모형은 아니에요. |
| 세부 야구 규칙 | 타격 경기의 주자·아웃, 투수 승패·자책 판정과 구원 승계 주자 등은 여전히 근사예요. 모든 공식 기록 규칙을 완전 재현한 엔진은 아니에요. |
| 구단 운영 | 실제 포지션별 전체 로스터, 40인 명단·옵션 횟수·웨이버·구단 예산·외국인 슬롯·연봉 조정 절차는 없어요. 계약 조항을 경력과 급여에 반영하는 현재 구조와 구분해야 해요. |

## Claude 메모리에 남길 결정

외부 메모리는 수정하지 않았어요. 다음 비자명한 결정을 메모리에 반영하면 좋아요.

1. `rookie_universe`의 세계는 개인 저장 단위예요. 일정은 재생성하고 현재 시즌 점수만 JSON에 저장하며, 라이트 과거 시즌 순위는 `LiteSeason.splits[].table`에 남겨요.
2. `rookie_story.put`은 기존 dict 참조를 유지해야 시즌의 다른 플래그 변경이 사라지지 않아요. 계약 만료·새 이적은 이전 `move`/`pin` 예약을 정리해야 해요.
3. 미국 적응 이력은 고졸 MLB 입단 때만 붙고, A/AA·24세 미만에만 적용해요. 예전 선수에게 추측으로 소급하지 않아요.
4. 유니폼 공유는 58구단, `CARD_V=7`이에요. 원단과 구단의 정체성 정보를 분리해요.
5. 공통 안타 계수는 .96, 대결 차이 완화는 12점을 넘는 구간이에요. 통계 테스트는 단일 작은 표본 대신 고정 다중 시드를 쓰고, 날짜를 바꿔도 활동 판정이 같도록 선수 생성 로그도 과거로 고정해요.
