# 야구선수 키우기 문구 전수 점검 · 2026-10-21

정식·라이트의 런타임 19개 모듈과 PC·모바일 81개 템플릿을 대상으로 리그·구단·보직·기록·중계·계약·이벤트·안내 문구를 점검했어요. 리그 코드, 저장 원본, 선택 키, 경기 확률과 성장·계약 금액 규칙은 유지했어요.

## 기존 저장 기록과 카드

`rookie_text.display`와 `baseball_text` 필터는 이전 JSON·기사·연표·선택지·카드에 남은 리그 명칭을 표시할 때만 교정해요. ‘KBO 1군은’→‘KBO는’처럼 조사도 맞추고, HTML 자동 이스케이프를 유지해요. 선수 이름이나 기록 자체를 DB에서 변경하지 않아요.

카드의 `CARD_V`는 **8**로 올려 저장용 PNG도 새 표기로 다시 만들어요. 이전 밸런스 실험 JSON과 문서는 당시 검증 기록이므로 원본을 일괄 치환하지 않았어요. 사용자 화면에 쓰이지 않는 모델 관리용 설명·과거 마이그레이션도 변경하지 않았어요.

해외 구단 카드 미리보기의 전성기 리그·최고 시즌·포지션별 수상명도 선택한 구단의 리그에 맞춰요. MLB 구단에 KBO·골든글러브가 고정되어 나오던 샘플 문구를 교정했어요.

## 검증

리그 약칭·구원 보직·기존 JSON 렌더링·HTML 이스케이프·상황과 점수의 일치·8회 적시타 이후 패배·사구 중계·멘토 효과 안내·대회 결과명을 검사하는 회귀 테스트 9개를 추가했어요. 전체 야구게임 테스트 **269개**와 Django 시스템 검사를 통과했어요.

마지막 해외 카드 샘플 교정 후에도 문구·미리보기 관련 **19개** 테스트를 다시 통과했어요.

PC에서 카드·리그·승부처·마이너행·협상 5개 장면을 열어 교정된 문구, HTTP 200, 가로 넘침과 JavaScript 오류가 없음을 확인했어요. 모바일 UA와 강제 모바일 쿠키로 390px 선수 카드도 직접 확인했어요.

메모리에 남길 결정은 `baseball_text`의 표시 전용 교정과 `CARD_V=8`이에요. 과거 이벤트 문구를 바꾸려고 선수 JSON·기사 원본을 덮어쓰지 않아요. 외부 Claude 메모리는 수정하지 않았어요.
