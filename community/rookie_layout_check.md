# 야구게임 화면 점검 — 2026-10-21

이전 세션에서 모델 처리 용량 부족으로 중단된 화면 점검을 이어서 마쳤어요.

## 수정

- 공용 제목 영역에 `min-width: 0`을 적용해 긴 선수 이름과 시즌 표시가 화면 밖으로 밀리지 않게 했어요.
- 선수 카드의 이름을 생략하지 않고 줄바꿈해요. 모바일에서는 번호·OVR를 왼쪽, 선수 소개를 오른쪽에 배치했어요.
- 라이트 모바일 요약 카드의 이름·소개와 별점·펼치기 버튼을 두 줄로 나눴어요. 등번호 99도 한 줄에 보여요.
- 자신감 `50/100`, `100/100`이 숫자 중간에서 갈라지지 않아요. 380px 이하에서는 마음·평판 수치를 두 칸씩 보여 줘요.
- 구장 전용 스타일이 늦게 적용되는 동안에도 배경 이미지의 원본 너비가 페이지를 밀지 않도록 공용 스타일에 최대 너비를 지정했어요.

수정 파일은 `static/css/rookie.css`, `static/css/rookie-stadium.css`예요. 다른 작업의 미커밋 변경은 보존했어요.

## 검증

- 임시 SQLite 테스트 DB를 사용해 운영·일반 로컬 DB와 분리했어요.
- 주요 화면 15개 × 320·375·390·430·768·1440px = 90개 조합을 확인했어요. 선수 생성, 훈련, 시즌 결산, 커리어, 리그, 기록, 수상, 은퇴 카드, 카드 보관함, 전당·오늘의 랭킹을 포함해요.
- 모바일 User-Agent와 `force_version` 쿠키를 함께 적용하고 `mobile.css` 선택을 확인했어요.
- 라이트 24개·정식 21개 미리보기 장면 × 320·390·1440px = 135개 조합에서 가로 넘침, 주요 글자 잘림, 게임 이미지 실패, JavaScript 오류가 없었어요.
- 선발 시험·선발 수업·불펜 전환·재정비·마이너행·계약 협상은 정식·라이트에서 각각 선택 후 결과를 확인했어요(12개). 라이트 요약 카드는 Enter로 펼치고 접었어요.
- 긴 이름, 큰 금액, 등번호 99, 자신감 100/100, OVR 100.0을 추가로 확인하고 수정 전후 스크린샷을 직접 검토했어요. 스크린샷은 `logs/rookie-layout-*.png`에 있어요.
- `py -3.10 manage.py check --settings=config.settings.local` 통과.
- `community.test_rookie_flow`, `community.test_rookie_preview`: 15개 통과. 생성부터 은퇴까지의 실제 요청 흐름을 포함해요. 실행 결과는 `logs/rookie-layout-flow-tests.txt`에 있어요.
- 넓은 기록표·리그 리더·탭 메뉴의 가로 스크롤은 의도된 동작으로 유지했어요.

브라우저는 전용 8017 포트의 임시 서버를 사용했어요. 기존 8001 포트와 세션이 달라 생긴 초기 검증 결과는 최종 집계에서 제외했어요. 반복 검사에서 구장 스타일이 적용되지 않은 시점에 이미지 원본 크기가 측정됐어요. 로딩 원인은 확정하지 않았고, 공용 CSS에 이미지 너비 제한을 추가해 해당 상태에서도 가로 넘침을 막았어요. 최종 전체 화면 검사는 뷰포트별 브라우저를 재사용하고 스타일 적용을 확인한 뒤 측정했어요.

## Claude 메모리 인계

모바일 카드의 이름은 생략 대신 줄바꿈하고, 번호·OVR와 소개를 분리해요. 작은 화면의 마음·평판 수치는 2열로 표시하고 분모와 소수점은 나누지 않아요. 새 숫자·배지를 추가할 때 320px에서 최대값도 확인해 주세요. 외부 메모리는 수정하지 않았어요.
