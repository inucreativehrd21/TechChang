# 야구선수 키우기 몰입 구조 검토 · 2026-10-20

**2026-10-21 후속 구현 완료:** 아래 초기 검토의 1순위였던 지속 라이벌과 구단별 대진·승패를 구현했어요. 감독 성향, 고졸 미국 적응, 기록 규칙과 극단 성적 보정도 추가했어요. 최신 적용 범위와 남은 한계, 최종 시뮬레이션 결과는 [커리어 개편 보고서](rookie_career_upgrade.md)를 기준으로 봐 주세요. 아래 표는 개선 전 진단 기록이에요.

현재 정식·라이트 코드와 이번 변경을 기준으로 정리했어요. 아래 개선 우선순위는 코드 검토에 따른 설계 판단이며, 사용자 플레이 실험 결과는 아니에요.

후속 MLB 계약 개편의 마이너 거부권·급여 조건·옵트아웃과 실제 영향은 [rookie_mlb_contracts.md](rookie_mlb_contracts.md)에 별도로 정리했어요. 해당 부분은 아래 초기 협상 설명보다 후속 문서가 우선해요.

## 몰입의 핵심은 선택이 다음 사건으로 돌아오는 경험이에요

FM의 공식 설명은 개인 목표를 계약·출전 경로와 연결하고, 약속의 조건·진행 상황을 명확히 알리는 데 초점을 둬요. 이 게임에도 ‘선택 → 상태 변화 → 다음 경기/계약 → 결과 확인’의 연결이 필요해요. [개인 목표와 상호작용 설계](https://www.footballmanager.com/features/individual-player-targets-and-interaction-logic)

또 에이전트와의 대화를 통해 이적 의사·협상 조건을 확인하고, 팬의 기대를 별도로 다루는 구조를 설명해요. 야구선수 한 명의 커리어에서는 감독 신뢰, 팬 인지도, 해외 구단 평가를 서로 다른 의미로 보여 주는 것이 적합하다고 판단했어요. [영입·에이전트 상호작용](https://www.footballmanager.com/features/recruitment-revamp), [팬의 기대](https://www.footballmanager.com/features/supporter-confidence)

## 이번에 연결한 게임 규칙

| 요소 | 실제 영향 | 범위와 회복 |
|---|---|---|
| 자신감 | 타석·투구 계산에 넘기는 실전 능력 보정 | 0~100, 최대 ±4, 영구 능력치는 유지해요. 라이트는 시즌 결산, 정식은 새 날짜에 선수 화면을 확인할 때 중립 50 쪽으로 20% 회복해요. 미답 장면이 있어도 회복은 적용돼요. |
| 감독 신뢰 | 라이트 보직 판정, 정식 다음 경기 타순·보직 판정 | 실력이 같아도 기회를 받는 정도가 달라져요. 0~100으로 제한해요. |
| 자기 관리 | 두 게임 훈련 효율, 라이트 부상 위험 | 훈련 ±15%, 라이트 부상 확률 배율 ±10%예요. 기존 부상 최소 확률은 유지해요. |
| 인기 | 기존 광고·연봉·올스타 효과, 해외 구단 협상 가능성 | 능력치로 바로 바꾸지 않아요. 낮은 자신감에 대한 팬 응원 완충은 최대 +0.8이에요. |
| 국제무대 평판 | 해외 협상 가능성 | 대표팀 참가와 성적으로 쌓이고 협상에 반영해요. |
| 기자에게 한 공개 약속 | 성적을 증명하면 신뢰·인기·자신감 상승, 미달하면 하락 | 반복 인터뷰로 평가 시작일을 미룰 수 없어요. 라이트는 다음 결산, 정식은 약속 뒤 최소 3일과 유효 타석/이닝 표본이 필요해요. |

라이트는 우선 콜업·강등 같은 중요한 면담을 보여 주고, 면담이 없는 시즌 중간에 55% 확률로 개인 승부·감독 대화·인터뷰·행실 중 하나를 보여 줘요. 무조건 클릭 수를 늘리지 않으려고 시즌당 추가 장면은 하나로 제한했어요. 실제 출전이 없으면 타석·투구 대신 일상 장면을 보여 줘요.

정식은 날짜별로 고정된 추첨을 한 번만 해요. 미결 장면은 유지하고, 새로고침으로 유리한 장면을 다시 뽑을 수 없어요. 일일 선택은 다음 실제 경기 계산과 훈련·보직에 반영돼요.

포스팅은 세 구단의 최초 제안을 저장하고, 한 곳을 고른 뒤 최대 세 차례 조율해요. 연봉 인상·핵심 역할 요구·기존 조건 수용·연봉 양보를 선택할 수 있어요. 실력·인기·국제 평판·자기 관리·구단 예산과 관심도가 합의 확률에 들어가요. 실패하면 수정 제안을 받고, 최종 결렬이면 원래 구단에 남아요. 계약한 역할은 초기 감독 신뢰를 통해 출전 기회에 반영해요.

라이트 국가대표는 모든 대회에 참가 인기 +6, 국제 평판 +3, 자신감 +2와 게임 안의 대회 수당을 줘요. 상위 성적은 추가 보상을 주고, 참가·최종 성적 보상은 대회별·시즌별 한 번만 지급해요. 병역 특례와 별개로 WBC·프리미어12에도 참가 동기가 생겨요. 정식에는 원래 국가대표 대회 흐름이 없어서, 이번 국가대표 보상 개편은 라이트 대회에 적용돼요.

## 구현·검증 시 주의할 점

- 상태는 `rookie_story.py`의 공용 계산과 기존 JSON 필드를 써요. DB 스키마 변경은 없어요.
- 새 선택지는 HTTP에서 화면 식별자를 검증해 중복 제출·예전 협상 조건 재사용을 막아요.
- 이전 포스팅 화면에는 이미 진행 중인 선수가 있을 수 있어 기존 제안 형식도 계속 받아요. 새로 발생한 포스팅부터 협상 흐름을 써요.
- 이미지 네 장은 제작 시 생성한 정적 WebP예요. 플레이 중 이미지나 Claude API를 호출하지 않아요.
- 로컬 미리보기의 선택은 임시 선수 객체만 바꾸며, 실제 선수·시즌 기록을 만들지 않아요.

## Claude 메모리에 남길 결정

- 정식은 `career`, 라이트는 `flags`의 기존 JSON 필드에 공용 상호작용 상태를 저장해요. `rookie_story.put`은 시즌 코드의 기존 dict 참조를 유지해야 해요.
- 일반 시즌 개인 승부는 현재 공식 기록과 별개예요. 다음 개선에서 경기 엔진을 중간에 멈추는 흐름을 먼저 만들어야 해요.
- KBO 10종 생성 원단을 등록된 해외 48팀도 가까운 배색으로 공유해요. `rookie_card.uniform_club`이 매핑하고, 구단명·이름·번호·카드 색은 원래 선수 정보를 유지해요.
- 공용 카드 스타일은 `rookie-card.css`, 캐시 버전은 `CARD_V = 7`이에요. 정식·라이트·PNG 출력에 같은 템플릿을 써요.
- `/rookie/preview/`는 DEBUG 전용이며, 장면 선택과 58구단 카드 개인화를 실제 DB 기록 없이 확인해요.

초기 연출 개편 검증은 6개 모듈 216개 테스트였어요. 후속 개편을 포함한 최신 검증 수와 결과는 커리어 개편 보고서에 남겨요.
