# 경기 환경·경기 전 대비·조건부 특성 — 구현과 디자인 인계 (2026-10-25)

라이트·익스트림 모드에 **경기 환경**(날씨·홈/원정·낮밤·구장·관중), **경기 전 대비**(시즌 루틴, 미디어데이·대표팀 기자회견), **조건부 특성** 11종을 넣었어요.
기능과 **Codex의 PC·모바일 디자인·특성 발견 연출이 로컬에 준비됐어요**. 운영 배포와 스위치 켜기는 아직 하지 않았어요.

## 지금 상태

- 엔진: `community/rookie_env.py`
- 저장: `LiteSeason.env`(JSON, 마이그레이션 `0054_liteseason_env`) — `{'routine': 루틴 코드, 'splits': {조건: 기록 합계}}`
- 스위치: `ROOKIE_ENV_ENABLED`(**기본 꺼짐**). 관리자 대시보드 → 게임 관리에서 켜기·끄기·환경 설정 사용을 저장해요. DB에 저장된 관리자 설정이 우선이며, 환경 설정 사용을 고르면 기존 설정/환경 변수 값을 따라요. 꺼져 있으면 경기·화면·기록이 지금과 똑같아요. 저장소는 `common.0017_game_controls`가 필요해요.
- 화면:
  - 비시즌 계획의 "훈련 강도 · 경기 전 루틴" 장면 — 올 시즌 예보 한 줄 + 루틴 6개(`_lite.html`의 `routines`, `name="routine"`)
  - 시즌 결산 덱의 "조건별 성적" 장면 — `_lite_env_splits.html`(`data-rl-env`)
  - 미디어데이·대표팀 기자회견 장면 — `_lite.html`의 `d.what == 'mediaday'`(기존 선택 카드 `_lite_choice.html` 재사용, 버튼 "말하기")
  - 시리즈 전광판 경기마다 `g.env` — `{weather, wind, time, park, crowd}`(전광판 디자인에서 날씨·구장 아이콘 등으로 쓸 수 있어요)
  - 조건부 특성은 기존 특성과 같은 자리(`c.traits`/`c.traits_seen`, 이름은 `rookie_lite.TRAITS`)에 들어가요. 선수 카드·커리어 화면의 특성 칸에 그대로 나와요. 드러날 때는 시즌 소식(`season.news`)에 "숨은 특성 발견 — …" 한 줄이 붙고, `season.env['revealed']`에 코드가 남아요.

## 디자인 연결 기록 (2026-10-25, Codex)

- 화면용 정보는 `community/rookie_env_presentation.py`에서 조합해요. 특성 추첨·공개 문턱·확률·효과·경기 난수는 바꾸지 않았어요. 공통 스타일은 `static/css/rookie-environment.css`, 조건 아이콘은 `_env_icon.html`이에요.
- 루틴: 새 준비 구장 이미지, 구장 성향·원정/야간/비/폭염 예상 경기 수, 아이콘이 있는 6종 라디오를 연결했어요. 선택 색과 ‘선택됨’을 함께 보여 줘요. 새로고침·상점 이동 시 루틴 선택을 복원하도록 브라우저 초안과 서버 초안도 보완했어요.
- 조건별 성적: 홈/원정·낮/밤·날씨·구장·계절/관중으로 묶고 타율 또는 평균자책점 막대를 보여 줘요. 8경기 미만은 회색과 ‘표본 적음’을 표시해요. 평균자책점은 낮을수록 좋다는 안내와, 조건별 수치가 특성 효과만을 뜻하지 않는다는 설명을 붙였어요.
- 미디어데이: 기존 `press-room.webp`를 재사용하고 마이크 진입 연출을 붙였어요. 대표팀은 태극의 두 색으로 표시해요. 실제 선택 폼·CSRF·POST 값은 유지했어요. 미리보기의 말하기는 화면 내 응답만 보여 줘요.
- 전광판: 저장된 `g.env`에서 날씨·바람 방향·낮밤·구장·관중을 보여 줘요. 돔은 중복 표시하지 않아요. 환경 스위치가 꺼지면 이 표시는 나오지 않아요.
- 특성: 11종에 조건 아이콘을 붙이고, 약점은 기존 Bootstrap 위험 색과 ‘약점’ 문구로 구분해요. `traits_seen`에 있는 것만 읽어서 미공개 특성이 노출되지 않아요.
- 발견: `season.env.revealed`와 해당 시즌의 발견·스카우팅 소식을 함께 읽어요(큰 경기 특성은 소식에만 남는 경로가 있어요). 각성 → 결정적 순간 → 특성 발견 → 수상 순서로 기존 대기열을 사용해요. 닫은 발견 연출은 커리어·연도·특성 조합별로 세션 안에서 반복하지 않고, 본문 ‘발견한 특성’ 장면은 계속 남겨요. 약점에도 축하 꽃가루는 쓰지 않아요. 동작 줄이기·건너뛰기·Escape·포커스 잠금/해제를 지원해요.
- 이미지 2종(준비 배경·투명 발견 오브젝트, WebP 합계 약 268KiB)은 기본 제공 ImageGen으로 생성했어요. [저장 경로·최종 프롬프트](../static/img/rookie/environment/README.md). 서버 AI 호출은 추가하지 않았어요.
- 미리보기: `/rookie/preview/?scene=environment`(투수 `&role=pitcher`), `?scene=traits`(약점 `&weak=1`), `?scene=mediaday`(대표팀 `&scope=intl`), `?scene=series&env=1`. 모두 DEBUG 전용이고 실제 선수·세션·게임 기록을 만들지 않아요.
- 검증 자료: `scratchpad/env-design/`. 메모리 DB로 실제 라이트·익스트림의 준비·결산·기자회견 PC/모바일 12개 응답과 스위치 꺼짐을 검증했어요. Playwright 격리 세션에서 PC 1280px·모바일 UA/쿠키 390px·320px, 라디오 키보드 조작·루틴 복원·발견 닫기/반복 방지·표본 표시·대표팀 미리보기 선택·동작 줄이기를 확인했어요. 운영 `0054` 적용·push·재시작은 하지 않았어요.
- 최종 검사: `py -3.10 manage.py check` 통과, `community.test_rookie_env`·`test_rookie_env_presentation`·`test_rookie_series`·`test_rookie_preview`·`test_rookie_flow` **51개 통과**. 큰 경기 특성이 소식에만 남는 경로를 화면에서 읽는 결정과 루틴 초안 복원 보완은 Claude 메모리에 남길 만해요.

## 규칙

- **환경은 커리어 난수로 진짜로 뽑아요**(같은 경기를 다시 열어도 같아요). 시즌 난수는 쓰지 않는 파생 난수라 다른 난수 순서를 밀지 않아요. 정식 모드는 후속(리그·날짜 기준 고정 예정).
- 날씨: 월별 확률(장마 6·7월, 폭염 7·8월, 한파 4월·10월 이후) + 연속성(앞 경기 날씨가 40% 확률로 이어져요). 돔 구장은 날씨가 없어요.
- 홈/원정: 프로는 실제 일정표(`club_fixtures`의 `home`), 고교·대학은 주말리그 홈/원정 번갈아, 대회는 중립 경기.
- 구장: 널리 알려진 것만 성향(돔·타자 친화·투수 친화), 나머지는 보통 구장(`PARK`).
- 보정은 그 경기에만, 작게:

  | 요인 | 효과 |
  |---|---|
  | 홈 / 원정 | 주요 능력(타자 컨택·선구안, 투수 제구·멘탈) +1 / −1 |
  | 구장·날씨 | **득점 환경(k)** 으로 다뤄요. 타자는 파워 +k·컨택 +k/2, 투수는 구속·변화구 −0.75k |
  | 구장 | 타자 친화 +2, 투수 친화 −2 |
  | 날씨 | 강풍 뒷바람 +2, 맞바람 −2, 한파 −2, 비 −1, 폭염 +1(투수는 체력 −3) |

- **시즌 루틴**(비시즌에 하나 고름). 평균 가치는 경기당 능력치 합 +0.33~+0.68로 비슷하게 맞췄고(하네스로 확인), 팀 구장과 역할에 따라 최선이 달라요.

  | 루틴 | 효과 |
  |---|---|
  | 컨디션 관리(기본) | 모든 손해 25% 감소 |
  | 원정 루틴 | 원정 손해 절반 |
  | 여름 체력 관리 | 폭염 손해 없음 + 7·8월 +0.5 |
  | 궂은 날 대비 | 흐림·비·한파·강풍 +0.5, 궂은 날씨 손해 절반 |
  | 야간 집중 | 야간 +0.6, 주간 −1 |
  | 홈 구장 맞춤 | 홈 구장 성향 효과 ×1.5(좋은 쪽도 나쁜 쪽도) |

  예: LG 타자는 궂은 날 대비, LG 투수는 홈 구장 맞춤, SSG 타자는 홈 구장 맞춤, 키움(돔)은 원정 루틴이 가장 좋아요.
- **미디어데이·대표팀 기자회견**: 가을야구 결승·국제대회 결승의 결정적 순간 직전에 나와요. 효과는 기존 수치로만 주고 우승 확률을 직접 바꾸지 않아요.

  | 선택 | 효과 |
  |---|---|
  | 차분하게 | 자신감 +3, 감독 신뢰 +2 |
  | 우승 선언 | 인기 +6, 자신감 +5. 우승하면 인기 +4와 ‘말한 대로’ 기사, 지면 자신감 −6·인기 −4와 ‘공수표’ 기사 |
  | 동료에게 공 | 감독 신뢰 +5, 인기 +1 |
  | 말 아끼기 | 인기 −2 |

  기사는 시즌 기사 맨 앞에 `[미디어데이]`/`[기자회견]`으로 붙어요.

## 조건부 특성 (11종)

환경에 따라 오르고 내리는 **숨은 특성**이에요. 효과는 주요 능력 두 개(타자 컨택·파워, 투수 제구·변화구)에 같은 값으로 그 경기에만 더해져요(환경·루틴 보정 위에).

| 코드 | 이름 | 효과 | 경기당 기대 가치(KBO 예) |
|---|---|---|---|
| `rain_man` | 비 오는 날의 사나이 | 비 +3 · 맑음 −0.5 | +0.2~+0.5(돔 팀은 낮음) |
| `summer_man` | 여름 사나이 | 7·8월 +2 · 4월 −2.5 | +0.5 |
| `home_tiger` | 안방 호랑이 | 홈 +2 · 원정 −1.5 | +0.5 |
| `road_reaper` | 원정 저승사자 | 원정 +2 · 홈 −1.5 | +0.5 |
| `night_owl` | 야행성 | 야간 +1 · 주간 −3 | +0.2~+0.3 |
| `dome_kid` | 돔구장 체질 | 돔 +1 · 바깥 구장 −0.3 | 돔 팀 +0.8, 그 밖 −0.4 |
| `big_stage` | 만원 관중 체질 | 만원 +2.5 · 한산 −2.5 | +0.3 |
| `cold_weak` | 추위에 약함 | 한파 −4 | −0.1 |
| `heat_weak` | 더위에 약함 | 폭염 −3 | −0.2~−0.4 |
| `october` | 가을 야구 사나이 | 가을야구 결승의 결정적 순간·시리즈 +4 | 큰 경기만 |
| `global` | 국제대회 체질 | 국제대회 경기·결승 +3 | 큰 경기만 |

- **부여**: 기존 특성 추첨(`roll_traits`)과 따로, 커리어 파생 난수로 붙여요(`rookie_env.roll_cond`). 그래서 기존 추첨 분포와 시즌 난수 순서는 그대로예요. 비율은 없음 46% · 하나 44% · 둘 10%이고, 특성마다 4~7%예요. 안방 호랑이와 원정 저승사자는 함께 붙지 않아요. 스위치를 켠 뒤 첫 시즌에 한 번(`flags['cond_rolled']`) 붙고, 기존 선수도 같은 확률이에요.
- **공개**: 고교를 마칠 때의 스카우팅 리포트(기존)에서 다른 숨은 특성과 함께 드러나거나, 그 뒤에 붙은 특성은 **조건이 8경기 이상 쌓인 시즌 끝**에 실제 기록과 함께 드러나요. 예: "숨은 특성 발견 — 비 오는 날의 사나이: 비 타율 .333(시즌 .267)". 큰 경기 특성은 그 무대(결정적 순간·국제대회)에서 드러나요.
- **적용 지점**: 정규시즌 경기(`_sim_chunks`), 결정적 순간(`_moment_stats`), 국제대회 경기(`play_intl`), 시리즈 경기의 내 기록(`_series_me`).
- 조건별 성적에 칸 두 개가 늘었어요: "여름(7·8월)", "만원 관중"(특성 공개의 근거로도 써요).

## 디자인 요구(Codex)

1. **루틴 고르기**: 예보 줄(내 구장·원정·야간·비·폭염 예상 경기 수)을 카드나 아이콘으로 보여 주면 루틴 선택의 근거가 잘 보여요. 루틴 카드는 지금 강도 게이지 스타일을 빌려 썼어요.
2. **조건별 성적**: 표 대신 홈/원정·낮밤·날씨·구장을 비교 막대로 보여 줘도 좋아요. 경기 수가 적은 칸은 흐리게.
3. **미디어데이**: 기자회견장 배경(기존 `press-room.webp` 재사용 가능)과 마이크 연출. 대표팀이면 태극 색.
4. **전광판의 `g.env`**: 경기 칩·라인스코어 옆에 날씨·구장·낮밤 표시.
5. **조건부 특성**: 특성 칸에서 조건(비·여름·홈/원정·야간·돔·관중·추위·더위·가을·태극)을 아이콘으로 보여 주면 "나만의 선수" 느낌이 살아요. "숨은 특성 발견" 소식은 각성·수상처럼 짧은 연출로 띄워도 좋아요(지금은 시즌 소식 한 줄). 약점 특성(추위·더위)은 색을 다르게.
6. 테크창 디자인 규칙(`techchang-ui`, `design-guardrails`)을 따라요.

## 켜는 순서(제안)

디자인 배포 시 `community.0054_liteseason_env`와 `common.0017_game_controls`를 적용해요. 배포가 준비되면 관리자 대시보드 → 게임 관리에서 시리즈 전광판과 경기 환경을 켤 수 있어요. 스위치 저장은 다음 요청부터 반영되며 재시작이 필요 없어요. 코드 배포·마이그레이션·서비스 재시작은 별도 운영 절차로 진행해요. 이번 로컬 작업에서는 운영에 적용하지 않았어요. 자세한 운영 화면과 검증 기록은 [관리자 개편 문서](admin-dashboard-remake.md)에 있어요.
