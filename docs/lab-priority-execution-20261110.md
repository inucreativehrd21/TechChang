# CTO 재평가 후 실행 계획

범위는 단일 관리자 연구실의 발행 안전성·복구·접근/파일/로그·감사·품질/사용량이에요. 판매·다중 고객 SaaS·납기 보장은 제외해요.

| 순서 | 작업 | 완료 기준 |
|---|---|---|
| 1 | 필수 제작 근거 완전성 | 단계 저장 실패 시 중단, 현재 원고와 연결된 검증·심사·최종 기록이 없으면 승인/공개 거절 |
| 2 | 실행 권한 검증 확대 | 원고 외 회의·안건·위클리·원장·지도 및 주요 파일 게시도 만료 실행의 변경을 거절 |
| 3 | 승인 파일 무결성 | 실제 파일 해시와 승인 스냅샷 연결, 승인 자산 비공개 보존, 변경·누락 시 승인 무효화 |
| 4 | 실증 자료와 사람 평가 연결 | 목록·소스·실행·원고 해시가 검증된 완전한 평가 묶음만 비교, 실패 사례 누락·자료 없는 JSON 판정 금지 |
| 5 | 버전 고정·장애/복원 검증 | 동일 소스 회귀 검사, 가용한 로컬 DB/OS에서 취소·저장 경합과 복원 검증, 실환경 미검증 항목 명시 |
| 6 | 관리자 평가 준비 | 고정 버전 실증 자료와 블라인드 평가표 준비, 실제 사람 평가 전 성능·경제성 통과로 표시하지 않기 |

운영 배포·재시작·운영 DB 마이그레이션 적용은 별도 요청 때 진행해요. 기존 사용자 변경과 저장소 밖 Claude 메모리는 보존해요. 유료 API와 서버 crew_work는 사용하지 않아요.

실행 결과·남은 제약은 작업 종료 시 이 문서에 이어 기록해요.

### 마지막 재개 및 전체 실행 자료 완성 (2026-11-11)

사용자가 구독 한도 해제 후 재개를 요청했어요. 23:01 KST에 현재 소스가 고정 지문과 같은 것과 미실행 사례가 `2-3-a`뿐인 것을 확인했어요. 기존 11개 사례의 파일 44개는 재개 전에 SHA-256을 남겼어요(`preserved-before-final.json`). 같은 출력 폴더에서 마지막 사례만 실행했고 23:23 KST에 프로세스가 정상 종료됐어요. 실행 로그는 `logs/lab-priority-pilot-final-20261111.log`예요.

실행해야 할 미시도 사례는 이제 없어요. 이전 인증·사용량·구독 한도 실패 6개도 그대로 포함했어요. 이 배치에서 B의 완료 조건은 충족되지 않았으며 B 전환이나 품질·경제성 개선은 확인되지 않았어요. 기본 프로필은 변경하지 않았어요.

`office.pilot_bundle.verify`로 **12개 전체 묶음**을 검증했어요. 목록·소스·실행 ID·원고·단계 기록·블라인드 사본·평가 증명서의 지문을 대조했고, 단계 순서도 확인했어요. 재개 전 파일 44개의 SHA-256이 모두 그대로였고, 현재 소스도 같은 고정 버전이에요. 최종 원고에 포함된 이미지 자산은 전체 0개예요. 라이브 상태는 idle이며 남은 생성 프로세스는 없어요.

평가표 12개 모두 실제 사람 평가 값은 null 그대로예요. 비교 보고서를 실행해 **사람 평가가 미완료라는 이유로 판정을 거절**하는 것을 확인했어요. 검증 로그는 `logs/lab-priority-final-integrity.log`, 비공개 결과는 `final-integrity.json`과 갱신한 `attempt-summary.json`이에요. 이 확인은 사람 평가를 대신하지 않아요.
