## 1. 현재 구조 (설계의 출발점)

- **특성은 두 계통**이에요. 성장·노쇠·부상을 배율로 바꾸는 **성장 배율형**(조기 개화, 대기만성, 연습벌레, 강철 체력, 큰 경기 체질, 경험파, 천재형, 유리몸)과, 상대 유형에 따라 한 타석 동안 능력치를 ±N 하는 **경기 보정형**(손잡이 특성 8개)이에요.
- 경기 보정형은 `rookie_handedness.matchup(타자, 투수)` 한 곳에서 처리해요. 정식·라이트·익스트림이 같은 `game_stats` 파이프라인(`Hands.annotate(...)`)을 지나므로, **조건부 특성도 같은 자리에 붙이면 세 모드에 모두 적용돼요.**
- 기록은 능력치에서 닫힌 수식(`rookie_sim.pa_probs`)으로 나와요. 컨택은 삼진·BABIP, 선구안은 볼넷·삼진, 파워는 홈런·장타 비율, 주루는 BABIP·3루타·도루로 이어져요. **능력치를 옮기는 특성은 세부 기록에 자동으로 드러나요.**
- 특성은 `traits`(타고난 것)와 `traits_seen`(드러난 것)로 저장돼요. 후천 특성은 JSON(`flags`/`career`)에만 두면 DB 마이그레이션이 필요 없어요.
- **엔진에 없는 것**: 날씨·경기별 홈/원정(일정표에만 있음), 땅볼/뜬공 구분, 경기 단위 포스트시즌 기록(지금은 시리즈 결과를 확률로 뽑아 뉴스 한 줄로 끝나요).

## 2. 이름 다듬기 (칭호 스타일)

원칙은 **2~6자 별칭 + 해요체 한 줄 설명**이고, 설명은 "조건 → 이득 → 대가" 순서로 써요. 실존 선수의 별명은 쓰지 않고 야구 은어에서 일반화된 말만 써요.

## 3. 신규 특성

### A. 능력치 치환형 (대가가 있는 몰빵)

- **원칙**: 더하는 만큼 다른 쪽을 깎아 OVR 가중치 합이 거의 변하지 않게 해요. **경기 중에만 적용**해요(손잡이 특성과 같은 방식). 저장된 능력치·OVR은 그대로라서 드래프트·전당·순위 규칙이 흔들리지 않아요. 카드에는 "표시 컨택 70 → 실효 78"처럼 둘을 같이 보여 줘요.
- **타자**: 똑딱이(컨택 +8, 파워 −8), 공갈포(파워 +8, 컨택 −8), 눈야구(선구안 +10, 컨택 −6), 발야구(주루 +10, 파워 −8), 철벽 수비수(수비 +10, 타격계 −4), 만능 평준화(높은 능력은 낮추고 낮은 능력은 올려 기복을 줄임).
- **투수**: 느림의 미학(구속 −8, 변화구 +5, 제구 +3), 돌직구 올인(구속 +8, 제구 −5, 변화구 −3), 제구 장인(제구 +8, 구속 −5), 변화구 장인(변화구 +8, 구속 −6), 이닝 이터(체력 +10, 구속 −5), 마무리 기질(체력 −8, 구속·멘탈 +5, 불펜 전용).

### B. 조건부 특성 (환경에 따라 올라가고 내려가요)

**경기 환경**을 새로 도입해요. 환경은 날씨(맑음·흐림·비·폭염·한파·강풍), 홈/원정, 낮/밤, 구장 성향(타자 친화·투수 친화·돔), 월, 관중, 상대 수준, 상황(득점권·접전·초반·후반), 휴식일·연투예요.

**환경을 어떻게 정하나 (모드별로 다르게)**

- **라이트·익스트림**: 시즌을 돌릴 때 **그 커리어의 난수로 경기마다 진짜로 뽑아** 경기 기록에 저장해요. 선수마다, 시즌마다 달라서 예측되지 않아요. 한번 뽑힌 값은 저장되므로 새로고침으로 다시 뽑을 수 없어요. 이 모드들은 시즌을 한 번에 시뮬레이션하므로 시드를 쓸 필요가 없어요.
- **정식**: 모든 회원이 같은 리그 일정과 순위표를 공유하므로 **리그·날짜 기준으로 고정**해요. "오늘 우천" 같은 소식이 회원 전체에게 의미가 생기고, 월드 허브·다른 회원 기록과도 맞아요.

**고정이 아니어도 재미를 더하는 장치**

- **결이 있는 확률**: 월별 날씨 확률(6~7월 장마, 8월 폭염, 11월 한파)과 연속성(비 온 다음 날은 흐릴 가능성이 높음)을 줘요. 완전히 무작위가 아니라 계절이 느껴져요.
- **희귀 사건**: 폭우 콜드게임, 강풍으로 홈런이 늘어나는 날, 우천 순연으로 선발 순서가 밀리는 날.
- **미리 보고 대응(결정 필요)**: 경기 전에 예보와 구장 정보를 보여 주고 선수가 대비를 고르게 해요(폭염 예보 → 체력 관리, 강풍 예보 → 공략법). 조건부 특성의 가치가 가장 커지는 장치예요. 대신 진행 화면이 길어져요.
- **구장 개성**: 구단마다 타자 친화·투수 친화·돔이 달라서 이적·FA 선택에 영향을 줘요.
- **보정 폭은 작게**: ±2~4로 두어 나쁜 날도 "오늘은 좀 불리하네" 수준이에요.

**조건부 특성 예시**: 안방 호랑이(홈 +3, 원정 −2), 원정 저승사자, 여름 사나이(7~8월 +3, 4월 −2), 비 오는 날의 사나이(우천 시 컨택·제구 +4), 야행성(밤 +2, 낮 −2), 한파 약점, 돔구장 체질, 만원 관중 체질, 강팀 킬러/약팀 사냥꾼, 휴식 후 강함/연투 약함, 초반 승부사/늦은 이닝 해결사, **가을 야구 사나이(포스트시즌 한정 +3)**, **국제대회 체질**.

**발동이 보이게**: 경기 로그에 "맑음·원정·야간"을 표시하고, 시즌 결산에 **조건별 성적**(홈 .281 / 원정 .249, 맑음/비 등) 작은 표를 보여 줘요. 특성이 발동한 경기에는 한 줄 로그를 남겨요.

### C. 후천 특성 (이벤트·상호작용에서 얻고 잃어요)

- **구조**: 타고난 특성(입단 때 0~2개)과 후천 특성을 분리해요. 후천 특성은 `flags['trait_state']`에 획득 계기·단계(Lv1~3)·남은 기간·해소 진행도를 저장해요. 얻을 때는 바로 뉴스로 알려요("새가슴이 생겼어요 — 인터뷰에서 흔들린 뒤로").
- **부정 특성(상처)**
  - **새가슴**: 인터뷰·이벤트 실패로 능력이 떨어졌을 때 약 25% 확률로 생겨요. 득점권·접전의 제구와 멘탈 −4. 해소는 다음 이벤트에서 자신감·신뢰를 얻는 선택에 성공하면 40%, 또는 시즌 종료 시 자신감 70 이상이면 해소 대상이에요.
  - 설화 체질(인터뷰 실수 반복), 부상 공포(큰 부상 뒤 복귀 시즌 불안정), 향수병(해외 첫 두 시즌 컨디션 −), 슬럼프 체질.
- **긍정 특성(성과)**: 강심장(결정적 순간 연속 성공), 불사조(재활 성공), 스승의 제자(멘토 이벤트 누적), 팬들의 영웅(수상 누적), 관록(35세+), 복수의 화신(라이벌 승부 승리 누적).
- **가드레일**: 시즌당 부정 특성 획득 1개, 부정 최대 2개·긍정 최대 2개, 상충 쌍(새가슴↔강심장)은 서로 덮어써요. 부정 특성은 지워도 약화 단계(흉터)가 남게 하면 악순환을 막으면서 이야기가 남아요.

### 세부 스탯에서 효과 보이기

1. **자동으로 드러나는 부분**: 위 표처럼 능력치 치환은 타율·홈런·볼넷·삼진에 바로 나와요.
2. **특성 효과 장부**: 시즌 결산에 "이 특성이 만든 차이(추정)"를 보여 줘요(예: 똑딱이 — 타율 +.010, 홈런 −6). 수식이 닫힌 형태라 특성 있음/없음을 두 번 계산해 타석 수를 곱하면 돼요. 기존 변화 장부(`_why`)와 같은 모양이에요.
3. **조건별 성적 표**: 홈/원정·날씨·시기 분할.
4. **카드·뉴스 문장**: "컨택형으로 변신한 시즌: 타율 .291(+.018), 홈런 9(−11)".

## 4. 특별 경기 전광판 (신규)

한국시리즈·디비전 시리즈·국제대회처럼 큰 경기는 지금처럼 "달 단위 한 줄"이 아니라 **1차전부터 마지막 경기까지 특별한 전광판**으로 보여 줘요.

### 지금은 어떻게 되어 있나

- KBO 포스트시즌은 `rookie_universe.kbo_final`이 시리즈 결과를 확률로 뽑아 뉴스 문장만 남겨요(와일드카드 → 준플레이오프 → 플레이오프).
- 한국시리즈는 최종 승부의 결정적 순간 장면 하나만 열려요. 다른 리그는 확률표에 따라 "7차전" 장면 하나예요.
- 국제대회(WBC·올림픽·아시안게임·프리미어12)는 `INTL`의 결과 등급 확률표로 결승 진출 여부와 메달이 정해지고, 결승만 결정적 순간으로 나와요.
- 일반 시즌 전광판(`_lite_board.html`)은 달마다 한 줄씩 넘기는 방식이에요.
- 따라서 **경기 단위 기록이 없어서 시리즈 시뮬레이터가 먼저 필요해요.**

### 대상 대회와 형식 (실제 대회 방식을 기본으로 단순화)

| 구분 | 대회 | 형식 |
|---|---|---|
| KBO | 와일드카드 | 2전(4위 1승 우위) |
| | 준플레이오프·플레이오프 | 5전 3선승 |
| | 한국시리즈 | 7전 4선승 |
| MLB | 와일드카드 / 디비전 / 챔피언십 / 월드시리즈 | 3전 2선승 / 5전 3선승 / 7전 4선승 / 7전 4선승 |
| NPB | 클라이맥스 시리즈, 일본시리즈 | 단계별 시리즈 + 7전 4선승 |
| CPBL | 대만시리즈 | 7전 4선승 |
| 국제 | WBC·올림픽·아시안게임·프리미어12 | 조별 → 녹아웃(또는 슈퍼라운드) → 결승 |
| 아마추어 | 봉황대기 등 | 단판 토너먼트 트리 |

NPB·CPBL의 정확한 단계와 어드밴티지는 구현 전에 확인해요.

### 전광판 구성

1. **헤더**: 대회 이름, 라운드, 형식(7전 4선승제), 날짜·구장·날씨(3의 B와 연결).
2. **시리즈 스코어**: 큰 숫자 "LG 2 : 1 KIA"와 우승까지 필요한 승수 점(●●○○).
3. **경기 레일**: G1~G7 칩(완료=스코어·승패 색, 현재=LIVE, 예정=회색, 불필요한 경기는 점선 "필요 시"). 칩을 누르면 해당 경기를 볼 수 있어요.
4. **라인스코어**: 이닝별 득점과 R·H·E, 결정적 순간 이닝 표시(★), 승·패·세이브 투수.
5. **내 기록 패널**: 이번 경기와 시리즈 누계(타자는 타수-안타-타점-홈런, 투수는 이닝-실점-탈삼진-결과)와 역할("G4 선발", "G6 대타").
6. **하이라이트 줄**: 기사체 속보("[속보] …").
7. **결정적 순간 통합**: 시리즈 향방이 갈리는 경기의 이닝에서 기존 결정적 순간 장면이 열리고 결과가 라인스코어에 반영돼요.
8. **종료 연출**: 우승 시 기존 연출(`.rl-mfx`: 꽃가루·메달 리본)을 재사용하고 시리즈 MVP를 알려요. 패배는 담담한 톤이에요.
9. **컨트롤**: 자동 진행, 일시정지, "이 경기 건너뛰기", "시리즈 끝으로", Esc, 동작 줄이기, 스크린리더용 라이브 영역(기존 전광판의 `data-rl-skip`·`seen` 방식을 확장).
10. **특별 스킨**: 일반 전광판과 구분되는 금색 포인트(한국시리즈), 국가 색(국제대회, 기존 `KOREA_COLORS` 재사용). 실제 구단 로고는 쓰지 않고 구단 색만 써요.

### 데이터와 엔진

- 새 모듈(예: `rookie_series.py`)에 **형식표**와 **경기 단위 시뮬**을 둬요. 기존 경기 모형(`rookie_sim`)을 재사용하고, 내 선수는 실제 능력치로, 나머지는 팀 전력 확률로 계산해요.
- **내 출장 규칙**: 타자는 주전이면 매 경기, 백업은 대타. 투수는 선발 순번(시리즈는 4인 로테이션)으로 등판, 불펜은 접전에서 확률적으로.
- **결정성**: 시즌 난수로 시리즈를 한 번 시뮬해 시즌 기록에 `series_log`로 저장하고, 화면은 그 기록을 **재생**만 해요. 새로고침해도 결과가 같아요. 기존 JSON 칸을 재사용할 수 있는지 구현 때 확인하고, 없으면 JSON 칸 하나를 추가해요.
- **기록 분리**: 포스트시즌 기록은 정규시즌 합계에 더하지 않고 "큰 경기 기록"으로 따로 쌓아요(은퇴 카드·커리어 페이지·시리즈 MVP).
- **정식 모드**: 하루 한 경기 진행에 맞춰 실제 날짜로 시리즈를 진행하고, 홈 화면에 "한국시리즈 3차전 오늘" 배너를 띄워요. 월드 허브의 순위·브래킷과 같은 시드를 써서 일치시켜요.
- **특성 연동**: 환경(날씨 등)을 경기 로그에 담아 조건부 특성이 시리즈에도 반영돼요. "가을 야구 사나이"·"국제대회 체질" 같은 특성이 가장 빛나는 무대예요.

### 위험과 주의

- **분포 변화**: 지금은 우승·메달 확률표로 결과를 정해요. 경기 단위로 정방향 시뮬하면 우승률 분포가 달라질 수 있어요. 하네스로 기존 분포에 맞추거나, 의도적으로 재조정하고 다시 검증해야 해요.
- 시즌 진행이 길어지므로 건너뛰기를 반드시 넣어요.
- 상대는 계속 가상 선수예요(실존 선수 이름 사용 금지). 국가 이름은 써도 돼요.
- 모바일에서 경기 레일과 라인스코어가 읽기 쉬워야 해요.
- 정식 모드는 크론(`rookie_daily`)과 맞물려요.

## 5. 균형과 안전장치

- **특성 가치 점수제**: 특성마다 −3~+3 점을 매기고 한 선수의 총합 범위를 제한해요.
- **치환 합계 보존**: 치환 특성이 OVR 가중치 합을 거의 바꾸지 않게 해요.
- **하네스 검증**: 기존 `rookie_balance` 시뮬레이션으로 특성별 평균 WAR 차이가 시즌당 ±0.3 안인지, 도달 리그·은퇴 연령 분포가 쏠리지 않는지 확인해요.
- **난수 순서 보존**: 손잡이 특성에서 쓴 방식(별도 난수기)을 그대로 써서 기존 커리어의 재현성이 깨지지 않아요.
- **기존 선수 호환**: 새 저장 항목이 없으면 지금과 똑같이 동작해요.
- 모든 새 문구는 해요체이고, 조사는 `rookie_text.josa`를 써요.

## 6. 단계 제안

| 단계 | 내용 | 규모 |
|---|---|---|
| 1 | 이름·설명 다듬기(기존 15개) | 작음 |
| 2 | `Traits` 모듈 + 능력치 치환형 12종 + 특성 효과 장부 | 중 |
| 3 | 경기 환경(라이트·익스트림은 커리어 난수 저장, 정식은 리그·날짜 고정) + 조건부 특성 12종 + 조건별 성적 표 | 큼 |
| 4 | 시리즈 시뮬레이터 + 특별 전광판 (라이트·익스트림의 KBO 한국시리즈부터) | 큼 |
| 5 | 다른 리그·국제대회·아마 대회 확장, 정식 모드 실시간 진행·홈 배너 | 큼 |
| 6 | 후천 특성(획득·해소 규칙, 이벤트 연동) | 큼 |
| 7 | 땅볼/뜬공(선택), 하네스 밸런스 검증, 카드·뉴스 마감 | 중 |

## 7. 정해야 할 것

1. **적용 범위**: 라이트·익스트림 먼저, 정식은 후속으로 갈지(제안).
2. **경기 환경 도입**: 날씨·홈/원정·낮밤을 새로 도입해도 되는지(단계 3, 경기 계산에 새 입력이 생기는 가장 큰 변경).
3. **경기 전 대비 선택**: 예보를 보고 대비를 고르게 할지(전략성 ↑, 진행 화면 길어짐).
4. **땅볼/뜬공**: 투수 특성을 뚜렷하게 하려면 필요하지만 기록 항목이 늘어요. 투수 치환 폭을 키우는 것으로 갈음할지.
5. **후천 특성 강도**: 부정 특성이 "지우면 흉터가 남는" 방식을 허용할지, 완전 삭제만 허용할지.
6. **익스트림 전용 고위험 특성**을 따로 둘지.
7. **특별 전광판 우선순위**: 어느 대회부터(제안: 한국시리즈 → 국제대회 결승 → MLB 포스트시즌), 정식 모드 실시간 진행을 같이 할지.
8. **분포 처리**: 시리즈 경기 단위 시뮬 때 우승률을 기존 표에 맞출지, 새 분포를 인정하고 재조정할지.
