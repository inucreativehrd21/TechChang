# 정식판 회원 맞대결과 익스트림 전체 리그 비활성화

2026-10-24 로컬 구현·검증 기록이에요. 운영 반영은 별도예요.

- 정식판의 일일 경기에서 실제 출전이 확정된 상대 팀 회원 선수를 찾아요.
  같은 리그·같은 일정의 경기만 연결하고, 휴식·드래프트 대기·은퇴·다른 리그는 제외해요.
- 실제 타자·투수의 경기용 능력치로 맞대결 타석을 계산하고, 같은 결과를 양쪽 박스스코어에 넣어요.
  한 쌍당 한 타석, 타자는 원래 출전 타석 한도(최대 4), 선발은 9타석,
  구원은 예정 이닝의 아웃 수까지 배정해요. 남은 타석은 기존 가상 상대 모형을 사용해요.
  전체 팀 경기를 타석 순서대로 재현하는 모형으로 바꾼 것은 아니에요.
- 상대도 타자이거나 직접 타석에서 만나지 않은 경우에는 같은 경기 출전으로만 표시해요.
  타석 성적과 팀 승패를 구분하고, 서로 경기한 팀 점수는 양쪽이 공유해요.
- 맞대결 그룹은 같은 트랜잭션에서 저장해 한쪽만 기록되는 일을 막아요.
  경기 경험치와 시즌 누적은 맞대결을 반영한 최종 경기 줄로 계산해요.
- 경기 결과 카드·일일 리포트·공개 선수 페이지에 상대 선수 링크와 결과를 표시해요.
  상대별 누적은 저장된 경기 JSON만 집계하고, 예전 경기의 맞대결은 만들어 넣지 않아요.
  다른 회원 JSON에는 선수 이름이나 계정을 복제하지 않고 선수 ID·당시 소속·역할만 남겨요.
  표시할 때 현재 공개 선수 이름을 조회하고 삭제된 선수는 표시하지 않아요.
- 익스트림의 전체 리그·구단 링크를 PC·모바일 공용 메뉴에서 숨겼어요.
  `/rookie/extreme/world/`도 404로 차단해 세계 계산을 실행하지 않아요.
  정식·라이트의 조회 기능과 익스트림 커리어 내부 경기 진행은 유지해요.
- 새 모델·마이그레이션은 없어요. 맞대결 화면의 CSS 캐시 키는 `matchups=1`이에요.
  감사 메모에 있는 기존 `flow=4` 수정은 그대로 유지해요.

## 검증

- 정식·라이트·진로·계약·HTTP 완주·세계 조회·감사 수정·맞대결 회귀 247개 통과.
- 추가 출전 경계와 익스트림 메뉴·직접 접근 검사 19개 통과(앞 검사와 일부 중복).
- 공용 경기 함수를 사용하는 스토리·세계·밸런스 회귀 58개도 통과했어요.
- 최종 `py -3.10 manage.py check`가 통과했어요.
- PC 1366px·모바일 390px에서 타자·투수 공개 페이지, 내 선수, 일일 리포트,
  익스트림 시작 화면 10개를 확인했어요. 가로 넘침과 JS 실행 오류가 없었어요.
- 화면 자료는 `scratchpad/member-matchups/`에 있어요. `preview.py`는 임시 테스트 DB에서
  실제 Django 응답을 렌더하고, `serve.py`는 그 HTML과 정적 자산만 로컬에 제공해요.
  모바일 응답은 모바일 User-Agent와 `force_version=mobile` 쿠키를 함께 사용했어요.
- 감사 메모의 반복 요청 제한을 확인했어요. 이번 화면 점검은 짧은 Django 요청과
  정적 응답 재생으로 진행했고, 테스트 사이 캐시를 비웠어요. 운영 보안 미들웨어는 변경하지 않았어요.

메모리에 남길 결정은 맞대결 양쪽 동시 저장, 과거 경기 소급 없음, 타석 성적과 팀 승패의 구분,
다른 회원 JSON에 이름을 복제하지 않는 방식이에요. 외부 Claude 메모리는 읽기만 했어요.
