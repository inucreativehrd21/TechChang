- Django check, 마이그레이션 일관성 검사, diff 검사를 통과했어요. 마이그레이션은 테스트 DB에서만 적용됐어요.
- 관리자 템플릿을 fixture로 렌더해 데스크톱·390px 화면을 확인했어요. 390px 뷰포트에서 문서 너비도 390px이고 승인 입력의 레이블이 연결돼 있어요. fixture의 폴링·일부 이미지 요청 오류는 실제 앱 통합 검증 결과로 해석하지 않아요.

## 실증 상태

첫 시도는 로컬 기본 API 설정 때문에 비용 차단에 걸렸어요. 실증 도구가 구독 CLI를 명시하도록 고쳤어요.

CLI 재시도의 첫 A 원고(`logs/lab-maturity-pilot-cli/1-a/`)는 호출 20회, 기록된 단계 시간 합 약 936.9초, 첫 심사 75점·필수 수정 6건, 최종 심사 78점·major였어요. 최종 치명 결함은 `verification_stale`이었어요. 공개된 글은 없어요.

재현 자료를 대조하니 편집 수정 뒤 팩트체크 해시는 맞았으나, 이후 수치 잠금이 문장을 삭제해 해시가 달라졌어요. 이 실행은 해당 경로의 후속 재검증을 추가하기 전에 시작한 프로세스였어요. 현행 코드에 삭제 후 재검증을 연결하고, 세 번째 검증이 실제 최종 원고를 받는 회귀 테스트로 고정했어요.

인프라 결함이 섞인 상태로 구독 사용량을 늘리지 않도록 후속 실증은 중단했어요. 이 기록은 결함 재현 자료이며 A/B 성능 비교 표본이 아니에요. 3주제·6편의 유효 비교와 사람 평가는 아직 완료되지 않았으므로 B를 기본값으로 바꾸지 않았어요.

## 운영 반영 전 남은 확인

유효한 6편 재실증·사람 평가, 운영 DB 마이그레이션, 1분 실행 cron 등록, 운영에서 웹 재시작과 작업 실행의 격리 확인이 남아 있어요. 명령과 순서는 `lab-maturity-operations.md`를 참고해요.
