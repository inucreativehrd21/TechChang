# 익스트림 모드 — 공개 경로와 출시 검증

현재 라이트 판의 사용자 표시를 **라이트 모드**로 바꿨어요. `/rookie/lite/` 주소와 저장된
선수·기록은 유지해요. 2026-10-24 사용자 요청으로 **일반 공개용 게임 경로**까지 구현했어요.
공개 여부는 `ROOKIE_EXTREME_ENABLED`로 정해요. 운영 반영 여부와 최종 검증 수치는
`logs/rookie-world-rollout/result.md`에 기록해요. 운영자 실험실 플래그와 공개 플래그는 별개예요.

## 준비된 범위

- `LiteCareer.mode`로 라이트와 익스트림을 구분해요. `community 0052`는 기존 커리어를 전부
  `lite`로 유지하고 DB 기본값도 두어 배포 중 구버전 프로세스의 저장도 받쳐요. 기존 선수의 수치·기록을 바꾸지 않아요.
- 라이트의 선수 조회·손님 이관·카드·명예의 전당·오늘의 랭킹·홈 집계에서 익스트림을 제외해요.
  일반 카드 URL로 익스트림 ID를 열어도 404예요. 같은 회원은 라이트와 익스트림을 각각 진행할 수 있어요.
- 시작 능력 +5, 잠재력 +8, 훈련 ×1.35, 정규 시즌 상대 수준 +5를 시제품에만 적용해요.
  훈련·잠재력 상한·기존 훈련 제한·노쇠는 유지해요. 초기 공개 계수이며 실제 플레이 분포를 보고 조정할 수 있어요.
- 학창 동기·프로 동기·해외 경쟁자 3명의 이름·능력·존중·경쟁·맞대결 전적이 저장돼요.
  경쟁자의 성장은 자기 나이와 잠재력으로 결정하며 플레이어 OVR에 맞춰 몰래 바꾸지 않아요.
- 학교·프로·해외·말년마다 3개씩, 총 12개 전용 이벤트를 구현했어요. 훈련·부상 위험·신뢰·관계에
  결과가 남고, 선택 전에 효과와 승부 확률을 보여 줘요. 같은 사건은 2시즌 쉬고, 한 시즌에는 한 번만 선택해요.
- 사건 ID·현재 시즌·소유자·행 잠금·조건부 갱신으로 중복 제출과 낡은 선택을 거절해요.
  실험실의 시즌 진행에도 별도 토큰을 확인해요. 훈련·부상 위험 보정은 해당 시즌 뒤 초기화되고 결과는 시즌 일지에 남아요.
  2026-10-24 후속 구현의 도전 성공·실패 능력치 변화는 이후에도 유지해요.
- `/rookie/extreme/`은 `ROOKIE_EXTREME_ENABLED=true`일 때 손님·회원에게 공개돼요.
  게임 목록에 세 번째 모드가 표시되고 선수 생성·일반 훈련·전용 이벤트·진로 선택·은퇴까지 직접 진행해요.
  명예의 전당·오늘 순위·은퇴 카드는 익스트림 경로로 분리했어요. 사용자 요청으로 전체 리그·구단 메뉴는 비활성화했고 해당 직접 경로는 404예요.
- 기존 운영자 실험실은 `/rookie/extreme/lab/`로 옮겼어요. 이곳은 여전히
  `ROOKIE_EXTREME_PREVIEW=true`와 활성 운영자 계정이 모두 필요하고 기본값은 꺼짐이에요.
  응답은 캐시하지 않고 검색 색인을 막아요.
- 실험실은 **전용 이벤트만 직접 선택**하고, 일반 경기·국제대회 참가·진로는 고정된 자동 정책으로 진행해요.
  공개 게임은 이 자동 정책을 사용하지 않고 일반 게임의 직접 선택 화면을 사용해요.
- 테크창 회원·역대 커리어 비교는 동나이·투타 유형·비슷한 능력 순으로 공개 DB 기록을 찾아요.
  다른 회원과 실시간으로 맞붙었다고 표시하지 않아요. 익스트림 전용 사건의 지속 등장인물 3명은
  별도의 가상 훈련 동료로 구분해요. 비교할 회원 기록이 없으면 빈 상태를 솔직하게 보여 줘요.

## 로컬에서 실행하기

운영 DB와 별개인 `logs/rookie-preview.sqlite3`와 로컬 메일함을 사용하는 전용 설정이 있어요.
PowerShell에서 저장소 루트 기준으로 실행해요. 운영 서버의 `.env`는 바꿀 필요가 없어요.

```powershell
$env:DJANGO_SETTINGS_MODULE = 'config.settings.rookie_preview'
$env:ROOKIE_EXTREME_PREVIEW = 'true'
$env:ROOKIE_EXTREME_ENABLED = 'true'
py -3.10 manage.py migrate --noinput
py -3.10 manage.py createsuperuser
py -3.10 manage.py runserver 127.0.0.1:8039
```

새로 만든 로컬 운영자 계정으로
`http://127.0.0.1:8039/common/login/?next=/rookie/extreme/lab/`에 로그인해요.
시드·투수/타자를 골라 선수를 만들고 이벤트 선택 → 이번 시즌 진행을 반복할 수 있어요.
공개 화면은 `http://127.0.0.1:8039/rookie/extreme/`에서 손님으로도 시험할 수 있어요.
시험이 끝나면 해당 PowerShell에서 두 환경변수를 제거해요.

## 반복 검증

```powershell
py -3.10 manage.py test community.test_rookie_extreme --settings=config.settings.rookie_preview
py -3.10 manage.py evaluate_rookie_extreme --settings=config.settings.rookie_preview --pairs 50 --allow-preview --output logs/extreme-report.json
```

두 번째 명령은 새 임시 테스트 DB에서 같은 초기 시드의 라이트·익스트림 커리어를 끝까지 비교하고
종료 시 DB를 제거해요. `pairs`는 두 모드의 한 쌍이며, 투수·타자를 번갈아 실행해요.
운영 설정 또는 MySQL에서는 거절해요. AI·유료 API를 호출하지 않아요.

2026-10-24의 2,000쌍(4,000커리어) 확인 결과는 다음과 같아요. 각 집단은 1,000커리어예요.

| 구분 | 시작 OVR 평균 | 최고 OVR 평균 | 시즌 수 평균 | 통산 WAR 평균 |
|---|---:|---:|---:|---:|
| 라이트 타자 | 36.84 | 67.11 | 18.27 | 52.24 |
| 익스트림 타자 | 41.84 | 74.92 | 19.70 | 55.02 |
| 라이트 투수 | 36.09 | 66.32 | 18.00 | 36.05 |
| 익스트림 투수 | 41.09 | 74.05 | 19.58 | 40.97 |

모두 은퇴까지 진행됐고 능력 25~99와 타격·투구 기록 범위를 확인했어요. 전용 이벤트 12종이 모두
관측됐고, 익스트림 승부는 성공 10,917회·실패 9,887회였어요. 최고 시즌 WAR의 99백분위는
라이트/익스트림 타자 11.6/12.5, 투수 8.0/8.6이었어요. MLB를 최고 리그로 기록한 비율은
타자 9.8%→39.2%, 투수 4.7%→25.6%로 늘었어요. 통산 수입의 99백분위도 비교했으며
익스트림 타자 581억·투수 485억원 수준으로, 같은 엔진의 라이트 상위 사례와 함께 검토했어요.

별도 400커리어(각 집단 100개)는 프로 타자 100타수·투수 30이닝 이상 시즌의 타율·ERA와
일지에 저장된 부상 결장도 수집했어요. 커리어별 프로 시즌 평균을 다시 평균한 타율은
라이트/익스트림 .287/.284, ERA는 3.09/3.41이었어요. 강한 상위 리그 진출이 늘어
능력 상승이 모든 리그의 성적 상승으로 직결되지는 않아요. 기록된 부상 발생은
타자 228/1,813시즌→332/1,985시즌, 투수 236/1,735시즌→298/1,940시즌이었어요.
위험 선택을 포함한 고정 자동 정책의 표본이며 모든 사용자 선택의 균형을 보증하지는 않아요.
이번 초기 공개 계수는 유지하되, 실제 이용자의 리그·부상·선택 분포에 따라 재검토해요.
원자료는 `logs/rookie-world-rollout/balance-4000.json`, `balance-detail-400.json`, `balance-summary.json`이에요.

## 정식 도입 방향과 남은 출시 조건

공개 경로·기록판·CSRF 포함 실제 HTTP 완주 검사는 구현·검증했어요. 858개 전체 회귀 검사도 통과했어요.
최종 소스에서 다시 검사하며, 투타·모드별 1,000개씩 총 4,000커리어의 종료·상한·기록 범위를 확인했어요.
별도 400커리어에서 충분한 프로 타수·이닝 표본의 타율·ERA와 부상 결장 기록도 수집했어요.
이는 고정된 자동 선택 정책의 재현 가능한 실험이며 모든 사용자 선택의 밸런스를 보증하는 수치는 아니에요.

라이트 모드와 같은 30분 커리어에 더 빠른 성장과 강한 경쟁을 넣어요. 일반 선수보다
강해졌다는 체감은 시작 능력·훈련에서, 긴장감은 상대와 관계·위험을 감수하는 선택에서 만들어요.
기존 엔진은 높은 잠재력의 장기 국내 잔류에서 극단적인 기록이 나올 수 있으므로 배율만
올리는 출시는 피하고, 모드별 대결 수준과 기록 분포를 함께 검증해야 해요.

| 영역 | 첫 균형 실험의 후보 | 지켜야 할 조건 |
|---|---|---|
| 시작 능력·성장 한계 | 시작 능력 +5, 능력별 잠재력 +8 | 확정 밸런스가 아니에요. 기존 선수에 소급하지 않고 엔진 상한을 지켜요. |
| 훈련 | 효과 ×1.35 | 잠재력 한계·노쇠·연속 훈련 제한 유지. 장비·관리팀 보정과 겹친 결과로 비교해요. |
| 상대 수준 | 익스트림 상대 평가 수준 +5 후보 | 표시만 강하고 성적은 폭주하지 않게, 동일 시드의 시즌 기록·난이도 곡선을 검증해요. |
| 경쟁자 | 학창 시절 동기, 프로 동기, 해외 경쟁자 3명 | 이름·능력·관계·전적을 저장해 시즌마다 이어져요. 성적에 맞춰 몰래 능력을 바꾸지 않아요. |
| 전용 장면 | 단계별 3개씩, 첫 출시 12개 | 성장·보직·관계·급여 중 최소 하나에 결과가 남고, 단순 대사 반복을 줄여요. |
| 기록판 | 익스트림 명예의 전당·오늘의 랭킹·카드 표기 | 라이트·정식 기록과 순위를 섞지 않아요. 같은 저장 파일에서 모드 전환은 금지해요. |

## 정식 도입 후 확장할 상호작용

아래는 공개 버전의 확장 후보예요. 현재 시제품의 12개 이벤트는 위 ‘준비된 범위’에 적힌
훈련·위험·신뢰·관계 효과까지 구현했으며, 급여·보직·계약·은퇴 시점의 전용 분기는 앞으로 검토해요.

- **고교·대학:** 라이벌과 합동 훈련(성장과 피로 교환), 주전 공개 경쟁(보직과 감독 신뢰),
  결승 전 사전 약속(성공 보상과 실패 관계 변화).
- **프로 적응:** 훈련 파트너 선택(경쟁자 관계), 새 구종·타격 접근 공동 연구(능력 분배),
  스타 마케팅 제안(인기·수입과 훈련 시간 교환).
- **해외 무대:** 라이벌의 같은 리그 진출(장기 비교), 현지 적응 동행(성장과 계약 선택),
  대표팀 주장 제안(신뢰·피로·대회 기회).
- **전성기·말년:** 경쟁자의 마지막 맞대결, 후배 멘토링(내 훈련과 팀 신뢰 교환),
  마지막 우승 도전(몸 관리·출전·은퇴 시점 선택).

경쟁자는 단순 매년 새로 뽑는 이름이 아니라 일관된 인물이어야 해요. 관계는 존중·경쟁·갈등으로
쌓고 장면 직후 화면과 시즌 일지에 실제 변화량을 보여줘요. 같은 이벤트는 2시즌 쉬게 하고,
나이·소속·이전 선택에 맞지 않는 장면은 발생시키지 않아요. 우월한 능력이 모든 보상을
자동으로 주는 구조 대신, 얻는 것과 포기하는 것을 선택 전에 알려줘요.

## 구현 순서와 출시 조건

1. `LiteCareer`에 `mode`를 추가하고 기존 행은 `lite`로 유지해요. 경쟁자·전용 장면 이력은
   해당 선수의 저장 상태에 두고, 시즌 기록·공유 카드·랭킹도 모드로 분리해요.
2. 성장 계수는 모드별 규칙으로 한 곳에서 적용해요. 공용 시뮬레이터나 기존 라이트 숫자를
   전역 수정하지 않아요. 금액·부상·국제대회·MLB 적응 보정과의 조합을 검사해요.
3. 경쟁자 성장과 대결을 저장하고, 사건 ID로 중복 POST·뒤로 가기·두 탭의 낡은 선택을 거절해요.
4. 단계별 전용 장면 12개를 현재의 장면 UI에 연결해요. 모든 장면은 서버 규칙과 정적 대사로
   실행하며 게임 플레이에 AI 호출이나 API 비용을 추가하지 않아요.
5. 같은 시드로 라이트·익스트림을 투타 각 1,000커리어씩 비교해요. 리그 진출·커리어 길이·
   능력·시즌 WAR·타율·ERA·부상·수입의 분포와 상위 1%를 보고 후보 배율을 조정해요.
   불가능한 능력·깨진 기록·커리어 막힘이 없어야 하고, 익스트림이 빠르게 강해져도 경쟁자
   이벤트의 유의미한 성공·실패가 모두 관측돼야 해요.
6. CSRF를 포함한 실제 HTTP 완주 검사, 손님→회원 이관, 모바일 키보드·구매·새로고침 검사를
   통과한 뒤 공개해요. 위 배율은 이 결과 전에는 출시 수치로 확정하지 않아요.

가장 작은 완성 범위도 **모드 분리 + 성장 + 지속 경쟁자 3명 + 전용 장면 12개 + 기록판 분리**예요.
배율만 먼저 공개하면 사용자가 기대한 ‘강해졌지만 계속 흥미로운 커리어’를 검증하기 어려워요.
