# 중단 작업 점검과 완료 기록

대상은 연동 안내 문구·라이트 단계 화면의 표현 개선과 사용자가 선택한 **익스트림 비공개 시제품**이에요.
이전 Codex 폴백·계정 연결 기능·대표 이미지 작업은 앞선 운영 반영이 끝났으므로 다시 변경하지 않아요.

## 화면과 문구

- 계정 연결 안내의 ‘선수 기록’ 대신 ‘연결해도 기존 데이터는 그대로 보존돼요’로 표현을 통일해요.
- HUD의 원형 표시와 사다리의 동그라미는 잘리지 않도록 하고, 이름만 따로 줄임 처리해요.
- 상점 본문 위 여백을 추가해 경계선과 드롭다운이 붙지 않게 해요.
- 클릭 이동 때 제목에 강제 포커스를 주지 않아요. 키보드 이동의 포커스 표시는 유지해요.
- 고정된 장면 영역 안에서 110ms 페이드 아웃·170ms 페이드 인으로 바꿔요.
  긴 내용은 안쪽에서 스크롤하고, 모션 줄이기 설정에서는 즉시 전환해요.
- 원래 폼·CSRF·입력 소유 관계와 구매 전 선택 보존을 유지해요.

## 시제품

- 모드·성장 규칙·지속 라이벌·12개 사건·운영자 실험실·반복 검증 명령을 구현해요.
- 기본 비활성·운영자 제한·일반 조회/랭킹/카드 제외·검색 색인 제외로 비공개를 유지해요.
- 기존 기록을 `lite`로 유지하는 0052와 구버전 쓰기의 DB 기본값을 검사해요.
- 실행법과 관측 결과는 [익스트림 시제품 안내](rookie-extreme-review.md)에 있어요.

## 검증 기록

- 모드·접근·CSRF·중복·소유자·효과·순위 분리·기존 데이터 보존 전용 검사 12개 통과
- 계정·구매 선택 보존 포함 관련 36개 검사 통과
- 100개 커리어(투수/타자·라이트/익스트림 각각 25개) 완주, 이벤트 12종·승부 성공/실패 관측
- PC 1440px, 모바일 390px·320px에서 단계 높이 유지·클릭 강조 없음·17px 상점 여백·페이드 동작·모션 줄이기·실제 구매 후 선택 보존·가로 넘침 없음 확인
- 익스트림 실험실도 PC 1440px·모바일 390px에서 직접 확인했어요. 모바일은 선택지·라이벌을 한 열로 표시해요.
- 클릭과 별개로 키보드 Enter 이동의 제목 포커스, 빠른 이전/다음 연타 뒤 정상 장면 복원도 확인했어요.
- 기존 운영 배포본에 이번 변경만 더한 격리 트리에서 `common community office` 전체 843개 검사 통과(212.011초)
- 현재 작업 트리의 Django 시스템 검사와 마이그레이션 변경 누락 검사 통과
- 캡처와 검증 결과는 로컬 `logs/rookie-ui-20261024/`에 보관해요.

## 운영 반영 대기

구현과 로컬 검증은 끝났어요. 운영 소스 28개 대상의 기존 해시가 모두 일치함을 읽기 전용으로
확인했어요. 2026-10-24 점검 당시 회원·프로필 각 30개, 커리어 267개, 시즌 2,514개이고,
0052는 아직 적용하지 않았어요. 이 집계는 점검 시점의 값이며 사용자 활동에 따라 늘 수 있어요.

새 소스 묶음 전송·격리 검사·운영 백업·0052 적용·정적 파일 수집·서비스 1회 재시작은
이 묶음에 대한 사용자 승인 후 진행해요. 운영 익스트림 플래그는 켜지 않아요.
승인 전 상태를 운영 반영 완료로 보고하지 않아요.

실행 자료는 `logs/rookie-ui-extreme-rollout/`의 manifest·integrity·배포 스크립트에 있어요.
이전 배포를 끝낸 Codex 폴백·소셜 연동·대표 이미지와, 향후 공개 버전의 밸런스 확정·기록판은
이번 비공개 준비의 미완료 항목으로 취급하지 않아요.

## 메모리에 남길 결정

장면 높이를 유지하는 내부 스크롤과 클릭/키보드 포커스의 구분, 익스트림의 기본 비활성·모드 경계,
전용 로컬 DB와 임시 DB 검증 명령을 Claude 메모리에 기록할 만해요. 외부 메모리는 수정하지 않았어요.
