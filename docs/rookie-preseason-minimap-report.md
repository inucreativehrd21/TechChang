# 라이트·익스트림 시즌 준비 미니맵 적용 보고서

작성일: 2026-11-08

## 변경 전

- 시즌 전 화면은 `이전/다음`과 장면 선택 메뉴를 사용했지만, 앞 장면의 필수 선택을 마치지 않으면 뒤 장면으로 이동할 수 없었어요.
- 상점, 비시즌 선택, 훈련, 강도·루틴이 한 줄의 진행 순서처럼 보여 원하는 메뉴에 바로 접근하기 어려웠어요.
- 시즌 시작 화면에서 무엇이 필수이고 어떤 메뉴를 아직 둘러보지 않았는지 한눈에 알기 어려웠어요.

## 변경 후

| 항목 | 적용 내용 |
| --- | --- |
| 이동 | 비시즌 화면 위에 시즌 준비 미니맵을 추가하고, 모든 메뉴로 바로 이동할 수 있게 했어요. |
| 필수 선택 | 익스트림 사건, 국가대표 소집, 비시즌 선택, 훈련 두 개의 완료 상태를 각각 표시해요. 이미 선택한 훈련 조합이 금지된 경우에도 변경 필요 상태로 표시해요. |
| 선택 메뉴 | 강도·루틴에는 현재 기본값이 적용됐음을, 상점·팀 소식·선수 정보에는 방문 여부를 표시해요. 방문 여부는 현재 시즌의 브라우저 탭에 저장해요. |
| 개막 확인 | 시즌 시작 화면에서 남은 필수 선택과 둘러보지 않은 메뉴를 각각 링크로 안내해요. 선택 메뉴는 건너뛸 수 있어요. |
| 시작 조건 | 필수 선택이 남으면 시즌 시작 버튼을 비활성화하고, 익스트림 사건도 기존 서버 규칙에 맞춰 필수로 검사해요. 서버 측 시즌 시작 검증은 유지해요. |
| 화면 | PC에서는 4열, 모바일에서는 3열 미니맵을 보여 줘요. 모바일에서도 메뉴 전체가 보이며 페이지 가로 넘침은 없어요. |

미니맵은 기존 경기 화면의 코드와 디자인 토큰을 사용했어요. 별도의 이미지 생성이 필요한 화면 요소는 없었어요.

## 구현 범위

- `static/js/rookie-flow.js`: 미니맵, 직접 이동, 상태 표시, 방문 기록, 개막 리마인더
- `static/css/rookie-flow.css`: 미니맵과 리마인더의 PC·모바일 배치
- `templates/community/games/_lite.html`: 익스트림 사건이 남았을 때 개막 버튼 차단, JS 캐시 버전 변경
- `templates/community/rookie_lite.html`, `templates/community/mobile/rookie_lite.html`: CSS 캐시 버전 변경

## 검증

- Django `manage.py check`: 문제 없음
- JavaScript `node --check`: 통과
- 브라우저 PC 라이트: 미완료 상태에서 개막 화면으로 직접 이동, 필수 선택 안내, 훈련·이벤트 선택 후 시즌 진행 확인
- 브라우저 PC 익스트림: 전용 사건 미해결 상태와 시작 차단, 사건 선택 후 미니맵에서 해당 항목 제거 확인
- 브라우저 모바일 익스트림(390×844, 모바일 User-Agent): 3열 메뉴 표시, 상점과 개막 화면 직접 이동, 가로 넘침 없음 확인
- 기존 커리어 진행 테스트 `community.test_rookie_flow`·`community.test_rookie_extreme`: 19개 모두 통과

## 동작 범위

방문 여부는 기존 선택 임시 저장 방식과 같이 `sessionStorage`에 보관해요. 같은 브라우저 탭에서 새로고침하거나 상점 구매 후 돌아와도 유지되며, 다른 기기나 새 탭에는 공유되지 않아요. 필수 선택의 실제 값과 시즌 시작 가능 여부는 기존 폼과 서버 검증이 결정해요.
