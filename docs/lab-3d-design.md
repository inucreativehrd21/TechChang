# 연구실 3D A안

## 디자인 방향

방 하나를 비스듬히 내려다보는 건축 모형이에요. 가운데 목재 상판과 인디고 다리의 회의 테이블, 뒤쪽 자료 서가와 작업석, 앞쪽 발행대가 연구 과정을 공간으로 설명해요. 8명의 기존 이름·역할과 머리 모양은 유지하며 옷은 사이트의 중성색과 인디고로 정리해요. 기하학으로 직접 모델링한 사람·가구·건축을 실제 WebGL 장면으로 렌더링해요.

- 색: 백색 #ffffff, 바닥 #f4f5f8, 벽 #e7e9f0, 잉크 #18181b, 인디고 #4f46e5. 피부·목재는 재료 표현에만 사용해요.
- 글꼴: 기존 Pretendard. 큰 제목과 짧은 소개, 실제 장면에 공간을 할애해요.
- 구성: 제목 → 장면과 선택 연구원 패널 → 키보드로 선택하는 8명 명부 → 실제 제작 상태 → 회의·발행 글·활동.
- 원칙: 시각적 강조는 입체 연구실 하나에 집중해요. 무의미한 숫자 대시보드나 가짜 실시간 지표는 넣지 않아요.

```text
연구가 글이 되는 공간                       연구실 위클리
┌──────────────────────────────┬─────────┐
│                              │ 선택한  │
│   자료실 / 집필 / 회의 / 발행   │ 연구원  │
│         3D 연구실             │ 활동    │
├──────────────────────────────┴─────────┤
│ 8명 선택 · 시점 초기화 · 움직임 · 회의 재생 │
└────────────────────────────────────────┘
실제 제작 단계 → 최근 회의와 글
```

일반 카드 대시보드를 피하고 공간 자체를 탐색 대상으로 골랐어요. 주변 정보는 기존 섹션 스타일을 사용하고 선택 패널만 장면 옆에 붙여, 실제 연구원과 기록의 연결이 보이게 해요. 모바일은 같은 콘텐츠를 한 열로 제공하되 정적 미리보기 후 사용자가 3D를 시작해요.

## 실행·접근성 경계

- 실제 작업은 기존 `/lab/live.json`, 최근 활동과 회의는 `/lab/state.json`을 사용해요. 대기 중인 캐릭터의 움직임은 공간 연출이며 현재 집필 중이라는 뜻이 아니에요.
- 회의 재생은 저장된 발언이며 현재 작업과 분리해서 표시해요. 원시 모델 로그·프롬프트를 새로 노출하지 않아요.
- 장면 밖 HTML 버튼으로 8명을 모두 고르고 활동을 읽을 수 있어요. 움직임 정지, 키보드 카메라, reduced motion, WebGL 실패 시 미리보기를 제공해요.
- Three.js 0.187.0을 로컬 정적 파일로 고정해요(MIT). React·외부 CDN 런타임·WebSocket·새 DB 필드는 필요하지 않아요.
- 장면은 보일 때만 갱신하고 DPR과 프레임 속도를 제한해요. 정적 가구는 재질별로 합쳐 draw call을 줄여요. 모바일·데이터 절약·동작 줄이기는 자동 시작하지 않아요.
