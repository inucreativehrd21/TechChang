# 투타 유형·만개·익스트림 도전

2026-10-24 후속 구현이에요. 이번 변경은 로컬 작업본에 반영했으며 운영 배포는 아직 하지 않았어요.
앞서 배포한 회원 맞대결과 익스트림 전체 리그·구단 비활성화는 유지해요.

## 리그와 구단 선택

정식판의 전체 리그·구단 화면에서 리그를 바꾸면 구단·학교 선택지를 즉시 교체해요.
새 리그에도 같은 구단 코드가 있으면 선택을 유지하고, 없으면 첫 구단·학교를 골라요.
시즌 기록 조회는 기존 `기록 보기` 버튼으로 실행해요. 후속 사용자 요청으로 라이트도 전체 리그·구단 메뉴를 숨기고,
라이트·익스트림의 직접 전체 리그 경로는 모두 404로 처리해요.

## 투타 유형

- 정식·라이트·익스트림 생성 화면에서 던지는 손과 타석을 각각 좌·우로 골라요.
- 생성 뒤에는 바뀌지 않아요. 저장 정보가 없는 기존 선수는 모두 우투·우타로 읽고, 기존 행을 일괄 수정하지 않아요.
- 정식은 `career.hands`, 라이트·익스트림은 `flags.hands`에 저장해요. DB 필드·마이그레이션 추가는 없어요.
- 선수 요약과 은퇴 카드에 표시해요. 카드 이미지 캐시 버전은 10이에요.
- 실제 타석 계산에 상대 투타 유형을 반영해요. 반대 손 투수 상대 컨택 +1.2, 같은 손 상대 −0.6이에요.
- 가상 투수·타자에도 유형을 부여했어요. 새 선수는 35% 확률로 아래 숨은 특성 하나를 추가로 받아요.
  기존 선수에게 새 특성을 소급 지급하지 않아요. 계승 특성은 새 선수의 포지션·투타 유형과 호환되는 것만 유지해요.
- 추첨은 별도 난수기를 사용해서 기존 시즌·이벤트 난수 순서를 바꾸지 않아요.

| 좌승사자 | 투수, 좌타자 상대 | 구속·제구 +3 |
| 우타 봉쇄 | 투수, 우타자 상대 | 변화구·제구 +3 |

## 라이트 전용 만개

사용자 확정대로 일반 각성 상한은 실제 동작과 같은 31세로 통일하고, 만개는 그 이후에만 나와요.
정식·익스트림에는 만개를 적용하지 않아요.

- 조건: 현역 프로, 32세 이상, 프로 7시즌 이상, 군 복무 중 아님, 각성 포함 잠재력 3성 이하,
  다섯 능력의 잠재력까지 남은 평균 간격 6 이하예요.
- 고유 장면 `늦게 핀 꽃`에서 도전하거나 한 시즌 미룰 수 있어요. 도전은 커리어에 한 번이고,
  미루면 기회를 쓰지 않아요. 다음 시즌에도 조건을 만족해야 다시 나와요.
- 성공 확률은 기본 55%, 연습벌레 +10%p, 지난 시즌 평균 이상 성적 +5%p예요.
- 성공하면 잠재력 77로 바꾸어 **총 4성**이 돼요. 이전 각성 횟수는 역사로 보존하고,
  `bloom.awaken_base`를 기준으로 새 별만 더해요. 이전 각성 때문에 즉시 5성이 되지 않아요.
- 쌓아 온 훈련이 실력으로 드러나도록 능력치를 새 잠재력의 96%까지 끌어올려요. 이미 더 높으면 유지해요.
  실제 변화와 OVR를 기록하고 결과 장면에 전후 수치를 보여 줘요.
- 성공한 시즌부터 정확히 3시즌 동안 **음수 노쇠 성분만 70% 완화**해요. 훈련·기복·부상 효과는 별개예요.
  아주 늦게 성공한 경우 강제 나이 은퇴 상한만 해당 3시즌을 보낼 수 있도록 늘려요.
- 이후 기존 잠재력 접근·실적·대기 조건을 충족하면 나이 상한을 넘어서 **추가 각성 도전 1회**를 받아요.
  3시즌 완화가 끝난 뒤에도 이 기회는 남아요. 보류는 기회를 쓰지 않지만 기존 3시즌 대기는 적용해요.
  실제 도전하면 성공·실패와 관계없이 소모하고, 성공하면 5성이 돼요.
- 만개 자체의 실패에는 능력치 손실이 없고, 결과 장면을 확인한 뒤 다음 시즌을 준비해요.
- 남은 완화 기간과 추가 각성 상태는 `선수·리그·기록 → 만개 혜택`에서 볼 수 있어요.
- POST는 기존 CSRF·소유자 확인·행 잠금에 장면 ID 검사를 더해 중복 제출을 거절해요.

## 익스트림에서 큰 도전의 결과

사용자가 고른 방향대로 큰 도전의 실패에 손실을 집중했어요. 각 장면의 안전한 대안은 유지해요.

- 승부형 선택 성공: 능력치 2개 각각 최대 +3, 기본 선택 효과 외에 감독 신뢰 +4예요.
- 실패: 능력치 2개 각각 최대 −4, 해당 시즌 훈련 보정 −35%, 기본 부상 위험 외에 +6%p,
  기본 신뢰 효과 외에 −7이에요. 능력치 바닥 25, 시즌 부상 추가 상한 12%p를 지켜요.
- 능력치 변화는 유지하고, 훈련·부상 위험의 시즌 보정은 다음 시즌에 초기화해요.
  기본 익스트림 훈련 1.35배에 실패 보정이 적용되면 0.8775배예요.
- 상한을 넘은 기존 능력치도 성공 때문에 내려가지 않으며, 실패 손실도 최대 −4를 넘지 않아요.
- 확률과 효과를 선택 전에 보여 주고, 결과 알림에 실제 능력치 변화를 표시해요.
- 초기 능력 +5, 잠재력 +8, 최고 잠재력 99 등 기존 고점 구조는 유지해요.
