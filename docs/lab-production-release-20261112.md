## 실제 운영 검증

- 새 관리자 뷰를 운영자 권한의 RequestFactory 요청으로 렌더해 상태 200, 회의당 일괄 폼 1개, 새 저장 버튼·JS 연결을 확인했어요.

- 운영 대기열에 모델 생성이 필요 없는 칼럼 지도 갱신 검증 작업 #14를 등록했어요. 실제 실행기가 작업을 실행해 completed·exit 0으로 끝났어요. 별도 systemd 사용자 unit에서 RuntimeMaxUSec=45min·KillMode=control-group·UMask=0077을 확인했고, 웹 서비스와 ControlGroup이 달랐어요. 재시작·강제 종료 장애 주입까지 수행한 것은 아니에요.
- 운영 브라우저에서 홈·칼럼 지도·#137의 상태 200을 확인했어요. 홈에 두 유형 편성 안내, 지도에 유형 필터, #137에 실용 유형이 표시돼요. 모바일 390px에서는 실제 모바일 템플릿이 선택됐고 가로 넘침이 없었어요.
