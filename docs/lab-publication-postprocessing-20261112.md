- 수치 잠금의 문장 분리에서 이미지·링크·인라인 코드를 한 덩어리로 처리해요. 검증되지 않은 이미지 수치는 제외하지 않으며, 해당 도판과 캡션을 통째로 제거해 반쪽 이미지가 남지 않게 했어요. 인접한 정상 도판·작성자 표·코드 예제는 보존해요.

- 미채택 후보의 실제 심사가 `revision_decision.output.review`에만 있어도 심사 횟수와 점수를 집계해요. 정식 review와 중복 계산하지 않고, 미채택 후보를 최종 통과로 세지 않아요.
