# 야구 화면·전체 리그·일일 리포트와 익스트림 공개 준비

2026-10-24 사용자 요청에 따라 진행해요. 경쟁자 데이터는 **테크창 회원·역대 커리어 DB**를
쓰는 것으로 사용자 답변을 받았어요. 다른 회원과 실시간으로 대결했다고 표시하지 않아요.

## 작업 범위와 현재 상태

- 선택 확인을 이벤트·훈련·강도·대표팀 일정별 전광판으로 정리했어요. 제출 전 설명은 예상 효과이고,
  이미 적용한 선택은 선택 내용·결과·실제 수치 변화를 별도 영수증 형태로 보여줘요.
- PC 장면은 헤더 높이를 줄이고 선택지 3개를 한 줄에 배치해 고정 영역에 맞춰요. 800×600부터 1920×1080까지 확인했어요.
- 정식 경기 결과를 팀 이름·점수·승패·개인 기록으로 분리한 격자로 바꿨어요.
- 저장된 다른 회원의 동나이·투타 유형 기록을 비교해요. 동갑 우선, ±2세까지 검색하며 자기 계정·비활성·다른 모드 기록은 제외해요.
  가상 훈련 인물과 실제 회원 비교 표를 구분하고, 비교한 회원의 커리어 링크를 제공해요.
- 전체 리그·구단 조회를 정식·라이트·익스트림에 연결했어요. 소속 리그와 상관없이 커리어 시계에
  맞춰 대진·점수·팀 순위·가상 구단 선수 시즌 기록을 재생해요. 점수에서 개인 기록을 나누어 팀 득실점 합계를 지켜요.
  공개 회원 DB 성적은 별도 구역에 표시해요. 조회가 선수 진행 상태나 경기 난수를 바꾸지 않아요.
- 정식 일일 리포트는 어제(날짜 선택 가능)의 저장된 경기와 최근 7일을 분석해요. 기록에 없는
  구종·코스·결장 원인은 추측하지 않고, 상대 등급별 비교는 각 5타수 이상인 표본만 사용해요.
- 익스트림 공개 경로를 일반 플레이·생성·행동·전당·오늘 순위·카드·전체 리그까지 모드별로 분리했어요.
  원래 운영자 실험실은 `/rookie/extreme/lab/`로 옮겨 비공개를 유지해요.
  공개는 `ROOKIE_EXTREME_ENABLED=true`가 필요하고, 아직 운영 플래그를 바꾸지 않았어요.

## 반응 자료와 작성 방식

팬 반응은 독자적으로 쓴 상황별 192문장과 덧말 조합이에요. 같은 상황의 본문은 12시즌까지
겹치지 않게 고르고, 새로고침으로 반응이 바뀌거나 경기 난수를 소비하지 않게 해요.
해요체 반응 36개도 순환하고 기존 라이트의 해요체 3:커뮤니티 말투 7 비율은 유지해요.
정식 경기 뒤 반응은 별도 24문장과 실제 당일 기록으로 구성해요.

디시 공개 글에서 직관의 감정과 기록·투구 내용을 함께 이야기하는 패턴을 확인했어요.
[직관 후기](https://gall.dcinside.com/board/view/?id=ktwiz&no=6038327&page=1),
[등판 직관 이야기](https://gall.dcinside.com/board/view/?id=hanwhaeagles_new&no=17073691&page=1).
원문·작성자 닉네임을 복제한 댓글이나 실시간 수집물이라고 표시하지 않아요.
에펨코리아 야구 게시판은 이 작업에서 429 응답으로 접근하지 못했어요. 그곳을 전부 수집했다고 보고하지 않아요.

## 화면 기준

기존 Pretendard·인디고 #4f46e5·흰 바탕을 유지하고, 전광판만 #15183d/#a5b4fc/#eef0ff를 써요.
선택 요약은 제목 → 종류 → 선택 항목 → 효과 순서, 경기 카드는 팀 → 점수 → 승패 → 개인 기록 순서로 읽어요.
리포트는 구단 문서처럼 작성일·요약·핵심 숫자·긍정 관찰·보완 과제를 배치해요.

## 검증과 남은 일

- 새 기록·모드·CSRF·소유권·선택 보존·기존 회귀 관련 39개 검사 통과.
- 전체 리그의 승패·득실점 합계, 구단 타자 득점=팀 득점, 투수 실점=팀 실점,
  홈런≤안타≤타수≤타석·탈삼진≤아웃카운트를 검사했어요.
- 공개 전 4,000커리어(모드·투타 각각 1,000개)가 임시 DB에서 전부 은퇴까지 진행됐어요.
  각 시드 쌍이 끝나면 그 임시 회원을 지워 다음 실험의 경쟁자로 섞이지 않게 해요.
- 별도 400커리어에서 프로 타율·ERA·부상 결장을 확인했어요. 수치와 초기 공개 판단은
  `docs/rookie-extreme-review.md`와 `logs/rookie-world-rollout/balance-summary.json`에 있어요.
- CSRF 포함 라이트 4개·익스트림 2개 HTTP 완주 경로가 통과했고, 전체 회귀 858개가 통과했어요.
  최종 소스의 격리 회귀 검사를 다시 실행하며, 새 DB 마이그레이션이 없음을 확인했어요.
- 실제 PC/모바일 화면과 저해상도 선택지 검증은 `logs/rookie-world-rollout/verification.md`에 기록했어요.
- 이 문서 작성 시점에 운영 반영 전이에요. 최종 배포 묶음·백업·공개 플래그·서비스 검증 여부는
  `logs/rookie-world-rollout/result.md`를 기준으로 확인해요.

소스 변경 전 스냅샷은 `logs/rookie-world-rollout/before.tar`(소스만),
기준 해시는 baseline.json, 진행·검증 자료는 같은 폴더에 있어요.
외부 Claude 메모리는 수정하지 않았어요. 회원 비교의 읽기 범위·모드 경계·반응 반복 방지·리포트 표본 기준은
향후 메모리에 남길 결정이에요.
