# 공개 포트폴리오 주소

2026-11-15부터 공개·승인된 컬렉션과 레거시 포트폴리오는 `/portfolios/<표시 이름>/`을 사용해요. 주소 생성은 `community/portfolio_urls.py`, 화면 링크는 모델의 `get_absolute_url()`이 담당해요.

- 이름이 같으면 대표 컬렉션을 우선하고 나머지는 `이름-ID`로 구분해요. 저장된 다른 컬렉션 슬러그 및 `create` 등 기능 경로와도 충돌하지 않게 해요.
- 기존 컬렉션 슬러그와 레거시 `/portfolio/<user_id>/`는 쿼리 문자열을 보존한 301로 연결해요.
- DB 슬러그는 변경하지 않아요. raw HTML·에셋·편집·커피챗 경로는 기존 슬러그를 사용해요. 비공개 접근 제어와 HTML 샌드박스도 유지해요.
- 표시 이름을 바꾸면 공개 주소도 바뀌어요. 저장된 기존 슬러그 링크는 계속 연결되지만 이전 표시 이름 별칭을 영구 보관하는 기능은 없어요.

운영자 HTML은 DB 컬렉션 #3이 원본이에요. 이번 요청에서는 최초 화면 노출 방지, 표지의 KDC 심사 문구 삭제, 도입 문장 교체만 적용해요. 상세 KDC 설명과 자동 통계는 유지해요. 다른 최신화 후보는 별도 검토 결과로 전달하고 수정하지 않아요.
