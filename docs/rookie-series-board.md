## 결과와 분포 — 바꾸지 않았어요

우승·메달 확률은 지금 확률표와 **똑같아요**. 결과는 기존 규칙이 정하고 시뮬레이터는 그 결과에 맞는 경기 흐름만 만들어요.

| 무엇 | 누가 정하나 (기존 그대로) |
|---|---|
| 결승 진출 | KBO는 `kbo_final`(같은 씨앗으로 경기 단위로 다시 굴려 결과가 똑같아요), 그 밖의 리그는 `POSTSEASON` 표 |
| 우승 | 결승의 결정적 순간(성공 85% / 실패 15%) |
| 국제대회 단계·메달 | `INTL` 단계 확률표 + 결승은 결정적 순간 |
| 아마추어 결승 | 지금 규칙(첫 결승은 결정적 순간, 그다음은 반반) |

시뮬레이터는 시즌 난수를 쓰지 않고 커리어·연도·용도로 만든 파생 난수만 써요. 그래서 시즌 기록·우승·메달이 스위치와 상관없이 같아요.

**하네스** `py -3.10 manage.py evaluate_rookie_series --careers 200`이 같은 시드로 스위치를 끈 채·켠 채 커리어를 끝까지 두 번 돌려 시즌마다 우승·메달·수상·순위·은퇴가 같은지, 그리고 경기 흐름이 일관되는지 확인해요(결과는 아래 "검증").

## 흐름을 만드는 방식

- **경기 단위**: 경기마다 정해진 승패가 나올 때까지 기존 경기 함수(`batter_game`·`starter_game`·`relief_game`)를 다시 굴려요. 이길 때는 내가 잘한 경기가 뽑히기 쉬워 내 기록과 팀 결과가 맞물려요. 내 타점·득점은 팀 득점을, 투수 실점은 상대 득점을 넘지 않아요.
- **형식**(실제 방식을 단순화):

  | 리그 | 라운드 |
  |---|---|
  | KBO | 와일드카드 결정전(2전, 4위 1승 우위) → 준플레이오프·플레이오프(5전 3선승) → 한국시리즈(7전 4선승) |
  | MLB | 와일드카드 시리즈(3전 2선승, 1~4위 면제) → 디비전(5전 3선승) → 챔피언십(7전 4선승) → 월드시리즈(7전 4선승) |
  | NPB | 클라이맥스 퍼스트(3전 2선승) → 파이널(6전 4선승, 리그 1위 1승 우위) → 일본시리즈(7전 4선승) |
  | CPBL | 와일드카드(3전 2선승) → 플레이오프(5전 3선승) → 대만시리즈(7전 4선승, 1위 직행) |
  | 국제 | WBC: 1라운드 4경기 → 8강 → 4강 → 결승 / 프리미어12: 오프닝 5경기 → 슈퍼라운드 3경기 → 결승(3·4위전) / 올림픽·아시안게임: 조별 3경기 → 준결승 → 결승(동메달 결정전) |
  | 아마추어 | 고교: 1회전 → 16강 → 8강 → 4강 → 결승 / 대학: 예선 → 8강 → 4강 → 결승 |

- **홈 배정**: 7전 2-3-2, 5전 2-2-1, 3전 1-1-1, 상위 시드가 1·2차전 홈.
- **결승의 결정적 순간**: 언제나 **시리즈를 끝내는 경기**에 있어요. 장면 전에는 경기 번호(N차전)만 정하고(장면 이름도 "한국시리즈 N차전"), 앞 경기들의 승패는 결과가 정해진 뒤에 만들어요. 그래서 전광판은 **결정적 순간이 끝난 뒤(시즌 결산)** 에 보여야 해요 — 장면 전에 앞 경기를 보여 주면 안 돼요. 경기 수는 실제 7전 4선승제 결승과 비슷하게 4·5·6·7차전 ≈ 17·24·23·36%예요. 그 경기의 홈/원정과 이닝 점수는 장면(9회말 끝내기면 우리 홈 9회 득점)과 맞아요.

## 디자인 요구(Codex)

전광판 틀의 훅을 그대로 쓰면 돼요(`_series_board.html` 맨 위 주석).

1. **헤더**: 대회 이름·라운드·형식(7전 4선승제), 결과.
2. **시리즈 스코어**: "LG 2 : 1 KIA"와 우승까지 남은 승수(●●○○). `wins`·`need`.
3. **경기 레일**: 칩마다 완료(승·패 색)·현재(LIVE)·예정(회색). `[data-sb-rail] li`.
4. **라인스코어**: 이닝별 득점·R·H·E, 원정이 위·홈이 아래, 9회말 X, 끝내기 표시, 결정적 순간 이닝 표시.
5. **내 기록**: 경기 줄(`me.text`), 결장이면 "출전하지 않았어요".
6. **재생**: 1차전부터 자동 진행·일시정지·다음 경기·시리즈 끝으로. 동작 줄이기(`prefers-reduced-motion`)면 정적 표시, 스크린리더는 `[data-sb-live]`에 진행 상황을 읽어 줘요. 기존 전광판(`_lite_board.html`)의 `data-rl-skip`·`seen` 방식과 맞춰요.
7. **종료 연출**: 우승이면 기존 `.rl-mfx` 이펙트(꽃가루·메달 리본) 재사용. 실제 구단 로고는 쓰지 않고 구단 색(`team.color`, 국가대표는 태극 색 `#CD2E3A`/`#0047A0`)만 써요.
8. **위치**: 시즌 결산 화면의 결정적 순간 결과 아래(`_lite.html` 결산 블록)에 들어가 있어요. 모바일은 라인스코어·경기 칩 모두 가로로 스크롤하고, 선택한 경기 칩을 자동으로 보여 줘요.
9. 테크창 디자인 규칙(`.claude/skills/techchang-ui`, `design-guardrails`)을 따르고, 색을 바꾸면 라이트 테마 액센트(인디고 #4f46e5)와 충돌하지 않게 해요.
