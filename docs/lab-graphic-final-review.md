# 연구실 그래픽 마무리 · 2026-10-31

이전 세션의 B 배경·8명·plate 어댑터를 이어받아 실제 화면 연결과 PC·모바일 검증을 완료했어요. 사용자 첨부 이미지에서 한빈·수정·윤성의 다리가 책상 밖으로 나오고 발이 뜨던 문제를 수정했어요. 커밋·push·배포는 하지 않았어요.

## 수정 방식

- 기존 세 집필석은 독립 인물 스프라이트가 책상 위에 통째로 덮여 있었어요. 새 배경은 세 사람과 책상·의자·그림자를 함께 생성해 무릎이 책상 아래에 들어가고 발이 바닥에 닿도록 했어요.
- `plate-seated.webp` / `plate-seated-mobile.webp`를 사용해요. 기존 배경과 세 인물 스프라이트는 보존했고 런타임에서는 새 배경과 나머지 5명만 내려받아요.
- `layout.json`의 `integrated: true`는 세 인물의 중복 이미지·CSS 그림자만 생략해요. 8명 모두 이름·클릭·키보드 선택, 실제 활동, 회의 발언자 강조를 유지해요.
- 고정 시점에서 확대·축소·드래그·방향키 이동을 제공해요. 자유 회전은 없어요. 기존 WebGL 파일은 되돌리기용으로 남겨요.
- 사용자 안내의 “캐릭터의 작은 움직임”을 실제 구현에 맞는 “빛의 흐름과 강조 표시”로 바꿨어요.

## 검증

격리된 Chromium과 임시 테스트 DB에서 확인했어요. 실제 구독 모델 호출·메일 발송·업무 DB 쓰기는 하지 않았어요.

| 항목 | 결과 |
|---|---|
| PC 1440px, 모바일 390px | PASS · 가로 넘침 없음 |
| 모바일 UA + force_version=mobile | PASS · m-header/m-tabbar로 모바일 템플릿 확인 |
| 8명 장면 클릭/모바일 탭/명부 선택 | PASS |
| Tab·Enter로 8명 선택 | PASS |
| 확대·축소·초기화·방향키·마우스 이동·Escape | PASS |
| 움직임 정지, prefers-reduced-motion | PASS · flow 정지/애니메이션 없음 확인 |
| 실제 공개 상태 형식의 테스트 응답 | PASS · 윤성의 활동 강조와 상세 표시 |
| 회의 이전·다음·종료·선택 복원 | PASS · 세 집필석의 발언자 강조 확인 |
| 인물 이미지 로딩 실패 | PASS · 미리보기/명부 유지, 재시도 후 8명 복원 |
| 정상 화면 JavaScript 오류·연구실 자산/API HTTP 실패 | 없음 · 초기 브라우저의 공통 /favicon.ico 404는 별도 관측 |
| WebGL 다운로드 | 없음 |
| Django check | 통과 |
| office.test_live | 17개 통과 · disk full 로그는 의도된 실패 모의 테스트 |
| git diff --check | 통과 |

PC 장면 이미지 합계는 **289,110 bytes**, 모바일(DPR 1)은 **186,180 bytes**예요. 배경+5명 합계이며 layout JSON은 별도 2,053 bytes예요. 모바일 고해상도 기기가 PC 배경을 선택해도 이미지 합계는 PC와 같아 350KB 예산 안이에요. 공통 사이트 이미지·글꼴·CSS·JS는 이 수치에 포함하지 않아요.

실기기 성능·운영 서버 전송량은 측정하지 않았어요. 공개 활동과 회의 검사는 브라우저 응답을 대체한 테스트 데이터이며, 최종 캡처에는 테스트 활동을 쓰지 않았어요.

## Claude 메모리 인계 후보

`/lab/` 기본 엔진은 고정 시점 plate이며, **집필석 3명은 배경에 통합하고 5명은 독립 스프라이트**로 두는 결정을 남길 만해요. 좌표·선택 영역은 `static/img/lab/plate/layout.json`에서 관리해요. 외부 메모리에는 쓰지 않았어요.
