## 시각 방향

Pretendard와 인디고 `#4f46e5`, 흰 패널·중립 회색을 사용해요. 구장은 하나의 장소로 유지하고 빛과 계절 장식만 바꿔요. 어두운 면은 점수판 안에 한정해요. 달력은 연속된 시간축, 순위는 표, 반기 시상은 전기·후기 두 장으로 표현해요. 정보 없이 꾸미는 카드나 별도 포인트 색을 추가하지 않아요.

- PC 1366 / 실제 모바일 UA·`force_version` 쿠키 390·320에서 확인했어요. 넓은 점수판·달력·표는 자기 스크롤 영역 안에만 넘쳐요.
- `final-browser-audit.json`: 진행 중 최신 경기·일반/동작 줄이기/JS OFF × 세 폭, 페이지 넘침 및 스크롤 영역 밖 넘침 목록 모두 없음. 시각 7종별 이미지 요청 목록 포함.
- `static-audit.json`: 후기 화면·완료 화면의 동작 줄이기/JS OFF × 세 폭에서 경기 카드 모두 정적으로 표시. 이 추가 검사는 완료된 복사 DB의 표시 미리보기를 사용하므로 과거 시점의 엔진 계산 검증으로 사용하지 않아요. 실제 지정 시각의 일반 화면은 앞선 `after-second-*`·`after-post-*` 캡처로 따로 확인했어요.
- `legacy-audit.json`: 모든 스위치 OFF × 세 폭에서 기존 `.rs-stadium` 1개, 새 경기장·달력·시간 이미지·반기 수상 카드 0개, 넘침 없음.
- `boundary-audit.json`: 미진출 화면의 동작 줄이기/JS OFF × 세 폭, 18:00·22:00 실제 이미지/조명 전환, 입력·훈련 중 대기 후 정확히 한 번 자동 갱신을 재확인했어요.
- 키보드 순위 버튼·표 스크롤·정규 경기 펼치기, 자동 갱신 대기 및 실제 훈련 응답 후 재초기화까지 확인했어요.

이미지별 최종 프롬프트·용도·용량은 [clock/README.md](../static/img/rookie/clock/README.md)에 있어요. 생성 PNG 원본은 `scratchpad/rookie-full-remake/clock-originals/`에 보존했어요.

## 인계와 운영 경계

이번 작업은 로컬 구현·검증까지 완료했어요. 커밋·원격 push·운영 배포·운영 마이그레이션은 하지 않았어요. 엔진의 기존 미커밋 변경, 홈 모드 선택창 등 다른 작업도 유지했어요.

배포 묶음에는 표시 헬퍼·뷰 연결·공용 조각·PC/모바일 CSS 링크·JS·`static/img/rookie/clock/`의 WebP 10개가 함께 필요해요. 엔진 쪽 `0055`와 스위치 전환은 원래 기능 배포 계획에 맞춰 별도로 확인해야 해요. **`scratchpad/`의 복사 DB·PNG 원본·실행 및 캡처 자료는 배포·커밋 대상이 아니에요.**

메모리로 남길 만한 결정은 진행 중 시리즈의 최신 공개 경기 우선, 아래 접힌 순위표의 전체 누적 유지, 표시 전용 헬퍼 분리, 입력·훈련 중 자동 갱신 대기예요. 외부 메모리는 읽기만 했으며 수정하지 않았어요.
