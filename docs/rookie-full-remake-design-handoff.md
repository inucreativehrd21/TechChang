# 정식 모드 리메이크 — Codex 디자인 인계 (2026-10-25)

정식 모드에 **시간대 경기 · 전·후기 리그 · 반기 MVP · 가을야구**가 들어갔어요(기획: [rookie-full-remake-proposal.md](rookie-full-remake-proposal.md)).
기능과 테스트는 끝났고 화면은 **기존 부품을 이어 붙인 1차 상태**예요. 아래 항목의 디자인·연출을 맡아 주세요.
게임 규칙·기록 계산은 바꾸지 않아요 — 템플릿·CSS·JS·이미지만 다뤄 주세요.

## 0. 지켜야 할 것

- `design-guardrails`·`techchang-ui` 스킬 규칙: 라이브 토큰은 `premium.css`(라이트 전용, 인디고 `#4f46e5`). 어두운 면은 **전광판(시리즈 전광판·경기 중계 점수판)에만**.
- PC 1366px · 모바일 390px(그리고 320px)에서 **페이지 가로 넘침 없음**. 점수판 같은 넓은 표는 그 안에서만 가로 스크롤.
- 동작 줄이기(`prefers-reduced-motion`)와 JS 꺼짐에서도 모든 정보가 정적으로 보여야 해요(기존 `_series_board.html` 방식).
- PC·모바일이 같은 조각을 써요: `templates/community/games/_rookie_matchday.html`(경기장 칸), `_series_board.html`(시리즈 전광판), `_rookie_awards.html`(시상식). 모바일 페이지는 `templates/community/mobile/rookie.html`.
- 실제 회원 이름은 기존 공개 규칙 안에서만 — 새 문구에 회원 이름을 더 노출하지 마세요.
- 바꾸지 않을 파일: `community/rookie_*.py`의 계산(`rookie_league`·`rookie_clock`·`rookie_universe`·`rookie_halves`·`rookie_series`). 화면에 값이 더 필요하면 뷰 묶음 함수(`rookie_playback.stadium`·`_race`, `rookie_halves.post_view`)에 **키를 더하는 것**까지만 해 주세요.

## 1. 로컬에서 그 상황 띄우기

실제 `db.sqlite3`는 건드리지 않아요. 복사본 + 시계 이동 + 테스트 계정 자동 로그인 서버예요(포트 8010).

```bash
py -3.10 scratchpad/rookie-full-remake/rk_server.py seed                              # 복사본·마이그레이션·테스트 선수
py -3.10 scratchpad/rookie-full-remake/rk_server.py serve 2026-12-04T20:05            # 후기리그 저녁(경기 중)
py -3.10 scratchpad/rookie-full-remake/rk_server.py serve 2026-12-16T20:05 --mine     # 가을야구 1일차, 내 팀 결승 진출
```

- 처음 `serve`는 그 시각까지 경기를 따라잡느라 몇 분 걸려요. 시각을 앞으로만 옮기세요(복사본에 기록이 쌓여요). 처음부터 다시 하려면 `seed`.
- 스위치 `ROOKIE_FULL_SLOTS`·`ROOKIE_FULL_HALVES`·`ROOKIE_FULL_POSTSEASON`은 스크립트가 켜요.
- 캡처: `py -3.10 scratchpad/rookie-full-remake/cdp_shot.py URL OUT.png 390 mobile` — DevTools 기기 폭 에뮬레이션이라 390px이 정확하고, 가로로 넘친 요소 목록도 찍어 줘요(Chrome `--window-size` 캡처는 최소 폭 때문에 모바일이 잘려 보여요).
- `rk_test.sqlite3`(스크립트 옆에 생김)는 커밋하지 마세요.
- 지금 화면: `scratchpad/rookie-full-remake/shots/` — `second-half-*.png`(후기리그), `postseason-*.png`(가을야구 3차전 뒤), `awards-pc.png`(시상식).

## 2. 디자인할 것 (우선순위 순)

### D1. 가을야구 진행 중 상태 — 경기장 칸 (가장 중요)

**지금:** 경기장 칸 맨 위에 한 줄(`.rk-md-post-line`: "가을야구 한국시리즈 3차전까지 NC 1 : 2 키움 · 다음 경기 16일 22:00") + 라이트용 시리즈 전광판을 그대로 붙였어요. 그 아래에 **정규시즌 마지막 날 중계(LIVE 표시·11:00~22:00 칩)와 다음 시즌 개막 예고**가 그대로 남아 있어요.

**문제:**
- 전광판은 '끝난 시리즈를 1차전부터 재생'하는 설계라, 진행 중 시리즈를 열 때마다 1차전부터 다시 돌아요. 머리말 결과도 비어서 '대회 기록'으로 보여요.
- 지난 정규시즌 경기에 'LIVE'가 붙어 있어요. 가을야구 이틀 동안 칸의 주인공이 흐려요.

**원하는 것:**
- 진행 중 상태: "한국시리즈 · 3차전 끝 · 다음 4차전 오늘 22:00", 시리즈 전적(선승 점), 방금 끝난 경기를 먼저 보여 주고 앞 경기는 눌러서 보기. 끝난 뒤(30일 밤 이후)는 지금처럼 전체 재생 + 우승 축하(우승만, 준우승엔 축하 없음).
- 가을야구 기간(29·30일)엔 정규시즌 중계·칩을 접거나 아래로. '다음 경기' 카드는 다음 가을야구 경기(`md.post.next`)를 우선.
- 내 팀이 결승에 없을 때(`md.post.mine` 거짓): 지금은 결승 소식 한 줄뿐이에요. 탈락 회고 톤(라이트의 `reflection.webp` 쓰임새 참고)이나 "다른 구단 결승 소식" 카드로.
- 다음 경기 시각이 지나면 화면이 스스로 새로 고쳐져요(`data-rk-refresh`, 시각 + 60초). 새 경기가 들어왔을 때의 짧은 등장 연출(동작 줄이기면 없음).

**데이터** `md.post`(`community/rookie_halves.py` `post_view`):
`season`, `final`(한국시리즈·일본시리즈·월드시리즈·대만시리즈·우승 결정전), `mine`, `done`, `shown`(공개된 경기 수), `line`(한 줄 요약), `next`(`label` "16일 22:00", `at`, `no`), `champion`(끝난 뒤 `{code,name,short,color}`), `doc`(시리즈 전광판 문서 — 형식은 `rookie_series.series_doc()`; 공개된 경기까지만 들어 있고 진행 중이면 `rounds[0].result == 'pending'`, `doc.result == ''`).
경기 시각: 1군 7전제 29일 15:30·18:00·20:00·22:00, 30일 18:00·20:00·22:00 / 하위 리그 5전제 29일 18:00·20:00·22:00, 30일 20:00·22:00. 일찍 끝나면 남은 칸은 없어요.

### D2. 순위 레이스 — 전기·후기 표현

**지금:** 사이드 카드 제목 옆 작은 글씨 "KBO 리그 · 후기리그", 남은 경기는 반기 기준("후기 남은 58경기"), 전기가 끝나면 아래에 한 줄("전기리그 우승 NC 다이노스 — 후기리그 우승팀이 한국시리즈에서 맞붙어요" / 내 팀이면 "우리 팀이 전기리그 우승 — 한국시리즈 진출을 확정했어요").

**원하는 것:**
- 지금 반기가 한눈에: 전기/후기 구분 표시(탭 또는 배지), 반기 진행 막대(14일 중 며칠째).
- 전기 우승 구단 표시(표 안 행 표시 또는 배지). 내 팀이 전기 우승이면 '진출 확정' 상태가 눈에 띄게.
- 가을야구 기간엔 '정규시즌 최종 · 전기 우승 / 후기 우승' 요약으로 바뀌어야 해요(지금은 후기 표가 '남은 0'으로 남아요).
- 아래 접힌 "KBO 리그 · 모든 구단이 함께 치르는 시즌"(시즌 전체 순위표)에도 전기/후기/시즌 보기를 둘지 검토.

**데이터** `md.race`(`rookie_playback._race`): `label`, `half`(1·2, 전·후기가 아니면 없음), `rows`(`rank,name,w,l,d,gb,left,mine`), `mine`, `teams`, `games`(반기 경기 수 72), `final`, `first_champ`·`second_champ`(행 — `name`, `mine` 포함). 반기 표 전체가 필요하면 `rookie_universe.half_tables(p)`(`first`·`second`·`per`).

### D3. 시즌 달력 띠 (새 부품)

30일 시즌의 고저를 첫 화면에서 보이게 하는 가로 띠예요. 개막(1일) · 전기리그(1~14일) · **14일 전기 종료·올스타** · 후기리그(15~28일) · **22~28일 막판 주간** · **29·30일 가을야구** · 다음 시즌 개막. 오늘 위치 표시, 남은 날 수.
- 넣을 곳: 경기장 칸 머리 또는 페이지 머리말의 '시즌 2 · 82/144경기' 막대 대체.
- 데이터: `rookie_league.season_bounds(n)`, `rookie_clock.HALF_DAYS`(14)·`half_of(day)`, `L.SEASON_DAYS`(28)·`OFF_DAYS`(2). 필요하면 `stadium()`에 `calendar` 키를 더해 주세요(계산 함수는 그대로).
- 전·후기 스위치가 꺼져 있으면 띠도 숨겨요(`rookie_clock.split_on(day)`).

### D4. 반기 MVP — 수상 연출과 시상식

- 수상 축하 연출(`award_fx`, `_lite_award_fx.html`)은 반기 MVP(`kind='half'`)를 일반 상처럼 띄워요. `AWARD_HERO`에 없어서 다른 상과 함께 받으면 맨 뒤 순서예요. 반기 MVP만의 문구·장식(예: '전기리그 MVP · 14일의 주인공')을 정해 주세요. 시즌 MVP보다 한 단계 가볍게.
- 시상식 화면에 '전·후기 리그 MVP' 칸을 새로 넣었어요(`_rookie_awards.html`, `halves`). 지금은 타이틀 카드 모양을 재사용해서 값 줄이 길어요(`awards-pc.png`). 두 장(전기·후기)을 한 쌍으로 보이게.
- 선수 카드 배지('S2 전기리그 MVP')는 기존 배지 모양 그대로 — 따로 손볼 필요는 없어요.

### D5. 시간이 흐르는 홈구장 (이미지 — ImageGen)

정식 모드만의 시각 요소예요. 경기장 칸 배경 구장이 **실제 시각과 시즌 달력**에 맞춰 바뀌어요. 같은 리그 회원은 같은 시각에 같은 하늘을 봐요.

- **시각 6장 + 경기 없는 시간 1장**: 기존 `static/img/rookie/stadium.webp`(1536×1024)를 기준으로 **카메라·구도는 그대로, 빛·하늘·조명만** 바꿔 편집 생성해 주세요.

  | 키 | 언제 | 분위기 |
  |---|---|---|
  | `dawn` | 23:00~10:59 | 새벽녘 빈 구장, 방수포·물 뿌린 내야, 조명 꺼짐 |
  | `morning` | 11:00 | 맑은 오전, 짧은 그림자 |
  | `noon` | 13:00 | 한낮, 높은 해 |
  | `afternoon` | 15:30 | 늦은 오후, 긴 그림자(지금 그림에 가장 가까움) |
  | `dusk` | 18:00 | 노을 + 막 켜진 조명 |
  | `night` | 20:00 | 야간 조명 |
  | `main` | 22:00 | 조명 최대, 관중석 반짝임(메인 경기) |

- **시즌 장식 레이어 3장**(투명 PNG/WebP, 같은 크기로 겹치기): 개막전 현수막·만원 관중 / 막판 주간 깃발 / 가을야구 깃발·불꽃.
- 규칙: 인물·로고·글자·실제 구단 표식 없음(`static/img/rookie/README.md`와 같음). 한 장 300KiB 안팎 WebP. 화면 왼쪽 1/3(글자 자리)은 밝게·비워 두기 — 야간 그림도 어두운 부분은 오른쪽에. 서버 API 호출은 더하지 않아요(기본 제공 ImageGen).
- 제작 기록(최종 프롬프트·용도)은 `static/img/rookie/README.md` 또는 새 `static/img/rookie/clock/README.md`에.
- 연결: `rookie_clock`에 "지금 시각 → 그림 키" 함수 하나(예: `sky_key(now)`)를 두고 `stadium()`이 넘기면, 템플릿은 이미지 경로·장식 클래스만 바꿔요. 지금 시각 그림 한 장만 바로 불러오고 나머지는 늦게. 18:00·22:00 경기 시각에 화면을 열어 두면 조명이 켜지는 짧은 연출(동작 줄이기면 없음). 날씨 오버레이는 경기 환경 이식(2단계) 뒤라 지금은 빼요.
